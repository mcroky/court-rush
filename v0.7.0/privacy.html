계정과 선수 기록 안내

적용일: 2026-10-24 · 운영: Roky Studio

어떤 정보를 사용하나요?

아이디, 비밀번호 인증 정보, 선수 이름·포지션·경험치·훈련·코트 진행도와 경기 결과를 Supabase에 저장합니다. 이메일 주소는 입력받거나 인증하지 않습니다. 비밀번호의 저장·검증은 Supabase Auth가 담당하며 게임 데이터 테이블과 브라우저에 비밀번호를 저장하지 않습니다.

요청 제한을 위해 서버가 받은 접속 IP와 아이디에서 만든 해시와 요청 횟수를 보관합니다. 인증 서버·호스팅 제공자는 보안과 서비스 운영을 위한 접속 로그를 처리할 수 있습니다. 별도 광고·행동 분석 SDK는 사용하지 않습니다.

어디에 저장되나요?

GitHub Pages에서 게임 파일을 제공하고 Supabase 서울 리전에서 계정과 선수 기록을 처리합니다. 로그인 유지를 선택하면 로그인 세션을 해당 브라우저의 localStorage에, 선택하지 않으면 해당 탭의 sessionStorage에 저장합니다. 비밀번호와 복구 코드는 저장하지 않습니다. 경기 보상 재시도 자료는 해당 탭에 임시 저장합니다. 소리·효과 설정도 브라우저에 보관합니다.

이메일 없이 계정을 찾으려면

가입 때 한 번 제공하는 복구 코드를 안전한 곳에 보관하세요. 아이디와 복구 코드로 새 비밀번호를 설정할 수 있습니다. 코드가 없고 로그아웃한 상태라면 계정 복구를 보장할 수 없습니다. 로그인한 상태에서는 계정 관리에서 현재 비밀번호로 복구 코드를 다시 발급할 수 있습니다.

계정 삭제

게임의 내 선수 → 계정 관리에서 현재 비밀번호로 재인증한 뒤 계정을 영구 삭제할 수 있습니다. 계정, 선수와 연결된 성장·경기 기록을 함께 삭제합니다. 로그아웃이나 앱 삭제는 계정 삭제가 아닙니다. 직접 로그인할 수 없다면 운영자에게 삭제 요청 ↗을 보내세요. 비밀번호·복구 코드·로그인 토큰은 의견 폼에 보내지 마세요.

계정 자료는 서비스 제공 동안 보관하며 사용자가 삭제하면 운영 데이터에서 제거합니다. 제공자의 백업·보안 로그 보관은 해당 제공자의 정책에 따릅니다. 요청 제한 자료는 비밀번호와 분리해 요청 제한 목적으로 보관하며 만료 자료는 서비스 요청 시 정리합니다.

첫 공개판의 범위

현재 육성 도전은 AI 1대1 PvE입니다. 보상 중복과 포인트 소비는 서버에서 검사하지만 경기 시뮬레이션은 기기에서 실행됩니다. 사람끼리의 온라인 경쟁전이나 서버가 모든 입력을 검증하는 경기로 제공하지 않습니다. 유료 재화·구매·공개 순위는 없습니다.
