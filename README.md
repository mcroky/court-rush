# 코트러시

프리스타일을 좋아했던 기억에서 출발하는, 웹에서 바로 즐기는 3D 스트리트 농구 게임.

현재 상태: **온라인 1대1·육성형 웹 공개 테스트 v0.10.6** (2026-10-28). [웹에서 플레이](https://mcroky.github.io/court-rush/) · [Roky Studio](https://mcroky.github.io/roky-studio/). 자유 연습과 AI 1대1·3대3 육성을 플레이할 수 있다. 한국어·영어·일본어·간체 중국어를 선택할 수 있으며 언어 선택은 기기에 저장한다.

- 확정된 사용자 요구: 특유의 작화와 박진감 있는 농구, Roky Studio에서 바로 접속하는 웹 게임.
- 추천 엔진: **Godot 4.7.2 Standard + GDScript + Compatibility 렌더러**.
- 현재 범위: 반코트 하나, 자유 연습과 AI 1대1·6인 AI 팀전, 키보드·화면 터치 조작.
- 내 선수 육성: 가드·포워드·센터, 서버 저장,8단계 AI1대1과 AI3대3 성장 팀전, 스탯·스킬 훈련,138개 외형 아이템 상점. 일반 모드는 보상 없이 유지한다. 온라인 1대1은 내 선수 외형과 육성 능력치를 사용한다. 모바일 패키지는 별도 단계다.
- 온라인: 공개 대전방·자동 매칭의 별도 승패와 Elo 랭킹, 코드로 입장하는 비공개 연습방. 90초·11점, Render Free에서 한 경기씩 운영한다. 온라인 3대3은 다음 확장 단계다.
- 사용자 확정 이름은 코트러시 · COURT RUSH다. 기존 로컬 작업 폴더는 경로 호환을 위해 유지한다.

이메일 없이 아이디·비밀번호로 가입하고 복구 코드를 보관한다. 가드178cm·포워드190cm·센터204cm 중 한 선수를 만들고 AI1대1 코트8단계 또는 내 선수의 AI3대3 성장 팀전에서 경험치와 스탯/기술 포인트를 얻는다. 계정·선수·보상은 Supabase의 코트러시 전용 영역에서 관리하며 기존 탁구 자료/인증 설정은 유지한다. [로컬 미리보기](http://127.0.0.1:8791/) · [계정·출시 구조](docs/07-career-release.md) · [3대3 성장과 모바일 카메라](docs/18-team-career-and-mobile-camera.md). 진행 중인 기존 탭은 자동 초기화하지 않는다.

이 폴더에서 PowerShell로 실행한다. Node.js가 PATH에 없으면 설치된 Codex 번들 런타임을 찾는다.

```powershell
./Start-Preview.ps1
```

브라우저 주소는 **http://127.0.0.1:8791/** 이다. 서버는 이 PC에서만 접속할 수 있다. 서버 로그와 PID는 `artifacts/preview*`에 기록된다. HTML을 파일 탐색기에서 직접 열면 WebAssembly를 정상적으로 불러올 수 없으므로 로컬 서버로 실행한다.

## 조작

| 입력 | 동작 |
| --- | --- |
| 방향키 | 화면 기준 이동 |
| D 유지 | 슛 준비 → 도약 → 자동 릴리즈 |
| D를 0.36~0.50초에 놓기 | 초록 구간 타이밍 보너스 (+8%p, 최대 성공 확률 99%) |
| 골밑 D | 2.6m 이내 레이업 |
| 골대 방향 돌파 + D | 1.95m 이내·진입 속도 2.7m/s 이상·중앙 폭 ±1.35m에서 덩크 |
| D 짧게 톡 | 슛 페이크 (0.18초 미만) |
| 드리블 중 공을 두 손으로 잡은 뒤 | 드리블 종료. 방향키는 제자리 피벗, D는 슛. 이동·재드리블·크로스오버 불가 |
| A + 방향키 | 크로스오버와 방향 전환 |
| 수비 중 D | 손바닥으로 내려치는 블록 / 양손 공중 캐치 리바운드 |
| S | 짧게 전진하며 공 쪽 한 손을 뻗어 스틸 · 실제 손 접촉 때 판정 |
| W 유지 | 낮은 속도로 수비 이동 |
| Esc | 일시정지 / 재개 |

자유 연습의 **FINISH LAB → 디딤·방향 전환**에서 ↑로 달린 뒤 ←/→로 발 접촉·몸통/팔 회전·돌파를 확인한다. **느리게 연습**은 가까운 측면 시점이다. **크로스오버 연출**에서 ↑로 달린 뒤 ←/→ + A로 새 동작을 확인한다. **느리게 연습**을 켜면 전면 사선 시점에서 속임·바운스·반대 손 캐치를 볼 수 있다. 레이업 위치와 덩크 도움닫기도 선택할 수 있다. 덩크 도움닫기 위치에서 ↑로 약 0.5초 달린 뒤, 이동을 유지하며 D를 누르면 덩크가 나온다. 화면의 D · DUNK 표시로 발동 가능 여부를 확인한다. 골대 뒤에서는 일반 슛이다. 골밑 기술도 수비 경합으로 빗나가거나 블록될 수 있다.

1대1은 11점 선취 또는 90초 승부다. 동점이면 다음 득점으로 결정한다. 득점하면 상대 공격, 수비 리바운드/스틸 후에는 외곽선 밖으로 공을 빼야 한다. 모바일에는 이동 스틱과 행동 버튼이 있으며 가로 화면을 권장한다.

## 구현 내용과 한계

- 코드로 만든 툰 스타일 3D 캐릭터, 슬림한 성인 비율·카고 반바지·뒤로 쓴 모자, 원본 스트리트 코트.
- 무릎을 굽히는 달리기·낮은 크로스오버·한 발 레이업·한 손 덩크·슛 팔로스루와 착지 표현.
- 손에 붙어 있는 공은 도약 후 실제 릴리즈 위치에서 발사된다. 드리블 바운드와 효과음의 위상을 공유한다.
- 첨부 레퍼런스에 맞춘 작은 머리·긴 다리·가는 팔, 연속형 의상 메시, 각진 얼굴, 저채도 스트리트 의상.
- **캐릭터 가까이 보기**에서 실제 게임 모델 두 명을 확대 확인한다. 확인 중 경기는 멈추며 코트로 돌아가면 같은 위치로 복귀한다.
- 확대 화면의 **동작** 버튼으로 대기 → 달리기 → 크로스오버를 전환한다. 실제 경기와 같은 관절 계산을 제자리에서 보여준다.
- v0.5에서 팔다리 길이를 고정하고 크로스오버 후 뒷발 회수를 수정했다. 코트 카메라는 원근 투영과 가장자리 추적으로 변경했다.
- 얼굴·저지·면 티셔츠·데님에 생성한 원본 텍스처를 적용했다. 확대 보기의 **얼굴·원단 확대**로 표면을 확인할 수 있다.
- 사진처럼 보이던 얼굴·원단 초안을 그린 명암과 선 중심의 텍스처로 교체했다. 선수 모델은 약 2m 높이, 공은 지름 .25m, 림은 지름 .46m로 비율을 맞췄다.
- 어깨와 소매 연결, 팔꿈치 관절, 손과 엄지, 둥근 모자·신발 형태와 대기 자세를 수정했다. 발을 디딘 구간은 지면에 고정하고 관절 위치로 무릎 굽힘을 계산한다.
- 플레이 가능한 코트는 15×14m로 바로잡았다. 이동 경계·공 아웃 판정·코트 선을 함께 변경했다.
- 공 궤적, 수비 경합에 따른 슛, 림 튕김, 스틸·리바운드와 단일 소유권.
- 공격과 수비를 수행하는 AI, 점수·공격 제한·경기 종료·재경기.
- 직접 합성한 효과음 9종, 소리/효과 설정, 자동 일시정지, 조작 안내와 업데이트 내역.
- 소리·효과 설정은 브라우저에, 육성 선수·경험치·훈련·코트 기록은 계정별 서버에 저장한다. 로그인 유지를 선택하지 않으면 세션은 해당 탭에만 보관한다.

45본 스킨 리그와 자체 사람형 외형에 클립·절차적 접촉 보정을 함께 사용한다. 전문 농구 모션캡처, 패스·3대3·온라인 대전은 아직 없다. 원작과 동일한 아트 완성도를 주장하지 않는다.

리바운드와 블록은 전용 동작을 사용한다. 연습장의 **리바운드 캐치**와 **블록 타이밍**, **느리게 연습**으로 반복 확인할 수 있다. 리바운드는 두 손으로 받아 가슴으로 당긴 뒤 착지하며, 블록은 한 손 접촉으로 공을 쳐낸다.

**스틸 파고들기**에서는 S로 전진 디딤 → 한 손 뻗기 → 접촉 → 공 당기기/손 회수를 연습한다. 성공한 공은 손을 따라 드리블로 이어진다. 실제 손 접촉과 기존 확률 조건이 필요하므로 모든 시도가 성공하지는 않는다. **느리게 연습**으로 공이 있는 쪽 측면에서 동작을 확인할 수 있다.

## 다시 빌드하기

Godot 4.7.2 Standard와 같은 버전의 웹 export template, Node.js가 필요하다. 경로에 없는 실행 파일은 전체 경로로 호출한다.

```powershell
godot --headless --editor --path . --import --quit
godot --headless --path . --export-release Web
node tools/build_web.mjs
```

`build/web`가 실행 결과물이다. 빌드 스크립트는 엔진 설정을 읽고 웹 셸과 gzip 파일을 만든다. 현재 엔진·게임 파일은 압축 전 약 42.0MiB, 로컬 gzip 산출물은 약 13.7MiB다. 공개 Pages의 전송 압축은 호스팅 설정을 따른다. 새 빌드 뒤 브라우저를 새로고침한다. 효과음 원본을 다시 만들려면 `python tools/generate_audio.py`를 실행한 후 재가져오기·빌드한다.

### v0.6 드리블과 발 타이밍

A 크로스오버 · Z 턴 드리블 · C 투스텝 돌파 · V 비하인드 백 · X 헤지테이션. 방향키와 함께 사용하며, 동작이 끝난 뒤 다음 기술을 눌러 연결합니다. 투스텝은 공을 잡지 않고 드리블을 유지하는 두 번의 방향 전환입니다. 캐릭터 가까이 보기의 동작 버튼은 대기→달리기→크로스오버→턴→투스텝→비하인드→헤지테이션으로 순환합니다.

회귀 검사: `godot --headless --path . --script tests/footwork_test.gd`

달리며 골대 3m 안쪽에서 D: 레이업. 골대 방향으로 1.85m 안쪽 진입: 덩크. 1.05m 이내 제자리 덩크. 달리는 골밑 마무리는 짧은 개더 후 자동 도약하며, 멈춰서 짧게 D는 페이크입니다.

추가 검증: `tests/running_finish_test.gd`, `tests/duel_animation_test.gd`.

레이업 도약 확인: FINISH LAB의 `느리게 연습`을 켜고 레이업 위치에서 ↑와 D를 사용합니다. `보통 속도로 연습`을 누르면 원래 속도로 복귀합니다. 도약 회귀 검사: `tests/layup_takeoff_test.gd`.

박스아웃: 슛 이후 상대보다 림/공 쪽에 서서 W를 유지합니다. 뒤의 진입을 막고 D로 리바운드합니다. 연습장의 `박스아웃 위치`로 반복할 수 있습니다. `tests/boxout_test.gd`에서 입력·위치·접촉·탈출·AI·연습 전환을 검증합니다.

W를 누르면 공이 없을 때 낮은 수비 자세로 전환하며, 방향키 이동 중에도 상대를 바라봅니다. 슛 뒤에는 등으로 상대를 받는 박스아웃으로 이어지고 압박에 따라 자세가 달라집니다. 박스아웃 위치에서 느리게 연습을 켜면 접촉과 발 디딤을 측면에서 볼 수 있습니다. 자세 회귀 검사: `tests/defense_stance_test.gd`.


v0.6.22에서는 사이드바에서 **G 가드 / F 포워드 / C 센터**의 시험용 프로필을 선택할 수 있다. 가드는 이동, 포워드는 이동 리바운드, 센터는 높이와 박스아웃이 강점이다. 경기 전/종료 후 또는 자유 연습에서 변경하며 공중 동작 중에는 바꿀 수 없다. 선택은 현재 세션에만 유지하며 육성 저장은 아직 없다. **FINISH LAB → 림·박스아웃 경합**은 연습용 미스 슛을 사용한다. W로 자리 잡고 내려오는 공에 D를 맞춘다. 일반 경기에도 동일한 림 튕김/캐치 흐름이 적용되며 슛 성공 여부는 확률 판정이다.


v0.6.22: FINISH LAB → **돌파·수비 회복**. ←/→+A로 속인 뒤 ↑로 돌파하면, 라이벌이 헛디딤을 받으며 중심을 되돌리고 돌아서 추격합니다. 느리게 연습을 켜면 가까운 시점에서 접지와 회전을 볼 수 있습니다. 회복 도중 반복 기술로 동작을 다시 시작하지 않습니다.


### 모션 방식 비교 시제품

## 웹 공개·개인정보

공개 주소: https://mcroky.github.io/court-rush/ . GitHub Pages는 정적 게임, Supabase Edge Function은 아이디 인증/복구·선수 저장/훈련/보상을 제공한다. 이메일은 수집하지 않으며 내부 Auth 식별자 매핑은 서버 전용이다. 비밀 키는 공개 저장소나 게임에 넣지 않는다.

웹 수출과 셸 빌드 뒤 `./tools/Publish-Web.ps1 -Version 0.7.6 -Push`로 별도 `release/pages`의 gh-pages 브랜치를 게시한다. 게임과 연구 화면은 기본 주소에서 직접 열리고 버전 경로로 이동하지 않는다. 엔진/PCK만 버전별 디렉터리에서 읽어 캐시 혼합을 피한다. 기존 최신 버전 주소도 게임을 직접 로딩하고, 네트워크 이동 없이 주소 표시만 기본 주소로 정리한다. 이전 기본 화면이 캐시에 남아 있어도 주소 왕복이 발생하지 않는다. 후원 버튼은 페이지 최하단에 배치한다. 최초 공개 Pages 빌드 `f4845ed`와 Roky Studio 연결 `2dac919`를 실제 주소에서 확인했다.

서버는 보상량·포인트·단계 제한과 중복 지급을 검증하지만 AI 경기는 기기에서 실행한다. 첫 공개판은 솔로 PvE이고 서버 권위의 온라인 경쟁전·공개 순위·유료 재화가 아니다. 3대3은 설계 단계이며 공개 메뉴에 제공하지 않는다. Android/AAB·서명·실기기·Google Play 출시는 이 웹 배포와 별도다.


## 경기 사운드 (v0.7.3)

영어 해설27개는 로컬 Kokoro-82M으로 미리 합성한 짧은 WAV이며 런타임 TTS·외부 음성 API·마이크 권한을 사용하지 않는다. 득점/3점/레이업/덩크, 드리블5종, 블록/공중 리바운드/스틸/승리에 연결한다. 실패한 기술 입력이나 지상 공 줍기는 해설을 재생하지 않는다. 자체 합성 배경음악3곡(붐뱁94BPM, 펑크110BPM, 일렉트로122BPM)은 선택/순환/다음 곡과1.2초 크로스페이드를 지원한다. 기존 전체 소리 설정을 유지하며 Music/Voice/SFX버스 음량과 설정을 기기에 저장한다. 해설 중 음악은9dB 낮아지고 복귀한다. 일시정지·탭 이탈·선수 연구 중 음성은 중단, 음악은 위치를 보존한다. 네이티브 Android에서도 같은 Godot 노드·음원을 사용할 수 있으나 실기기 검증은 아직 하지 않았다.

온라인 1대1: 다른 이용자 자동 매칭, 기존 선수 외형·균등 능력치·성장 보상 없음. Render Free에서 한 경기씩 운영하며 최초 연결은 서버 준비 시간이 걸릴 수 있다. [구현·운영 기록](docs/23-online-duel-implementation.md).
