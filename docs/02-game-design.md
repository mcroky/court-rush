# 게임과 작화 설계

작성일: 2026-10-23 / 상태: 설계 및 v0.1 시제품 반영. 사용자의 후속 요청으로 1대1을 독립 모드로 추가했다. 아래 3대3 수치는 후속 설계이며 현재 구현 내용은 README와 검증 기록을 따른다.

## 1. 만들고 싶은 경험

**“패스로 빈 공간을 만들고, 페이크로 수비를 띄우고, 한 박자 빠른 점프로 공을 따내는 스트리트 농구.”**

사용자가 말한 옛 프리스타일을 초기 프리스타일1의 기억으로 해석했다. 정확한 플레이 시기·선호 포지션은 아직 확인하지 않았다. 현재 공식 사이트의 캐릭터나 후속작을 과거 기억과 같다고 가정하지 않는다. [프리스타일1 공식 가이드](https://fs.joycity.com/web/game/guide/list.do)는 참고 입구이며, 아래 경기 규칙·조작 수치는 이 프로젝트의 제안이다.

개별 캐릭터·로고·음악은 새로 제작한다. 시각적으로 계승할 감각은 길거리 패션, 과장된 비율, 선명한 실루엣, 단순하고 강한 명암, 큰 동작과 리듬이다.

## 2. 모드와 단계별 공개 범위

**자유 연습 → AI 1대1 → AI 3대3** 순서로 확장한다. 1대1은 테스트에만 사용하는 임시 모드가 아니라 계속 제공할 독립 모드다. 온라인도 1대1 초대 방을 먼저 검증한 뒤 3대3으로 확장한다.

v0.1 1대1은 사용자 한 명과 AI 한 명, 90초 또는 11점 선취, 일반 2점/외곽 3점, 15초 공격 제한으로 구현했다. 득점 후 실점한 쪽의 공격으로 재개하며 수비 리바운드/스틸 뒤 외곽 클리어가 필요하다. 동점이면 다음 득점으로 승부한다. 이후 사람이 함께하는 1대1에서도 같은 모드 규칙을 재사용한다.

후속 3대3 공개 목표는 다음과 같다.

| 항목 | 제안 |
| --- | --- |
| 모드 | 연습장 + AI와 3대3 한 경기 + 즉시 재경기 |
| 조작 대상 | 사용자는 선택한 한 캐릭터를 끝까지 담당, 아군 AI 2명·상대 AI 3명 |
| 코트 | 야외 반코트 1개, 고정된 골대 1개 |
| 역할 | 가드·포워드·센터. 수치만 바꾸지 않고 체형·동작·활약 영역을 구분 |
| 경기 길이 | 3분, 공격 제한 15초를 시작값으로 시험 |
| 점수 | 일반 2점, 외곽선 밖 3점. 동점이면 다음 득점으로 승부 |
| 기본 동작 | 이동·드리블·패스·슛·페이크·레이업·덩크·수비·스틸·블록·리바운드·박스아웃 |
| 공개 UI | 시작, 역할 선택, 조작 안내, 경기, 결과, 설정, 업데이트 |
| 후속 범위 | 사람끼리의 3대3, 방 생성·참가, 이후 매치메이킹 |

캐릭터 성장·장비 능력치·상점·랭크·관전은 첫 공개 범위 밖이다. 기본 캐릭터만으로 공격과 수비의 재미를 먼저 만든다. 역할별 추가 기술도 기본 판정이 안정된 뒤 확장한다.

## 3. 한 경기의 흐름과 반코트 규칙

시작 → 역할 선택 → 짧은 조작 연습 → 체크볼 → 공격/수비 반복 → 결과 → 재경기.

- 경기 시작은 중앙 외곽 체크볼. 득점하면 실점한 팀이 체크볼로 재개한다.
- 수비 리바운드나 스틸로 소유권이 바뀌면 공을 외곽선 밖으로 빼야 공격할 수 있다. 화면에 “외곽으로 공 빼기”를 표시한다.
- 공격 리바운드는 클리어 없이 계속 공격하며 공격 시간을 10초로 재설정한다.
- 공이 코트 밖으로 나가면 마지막 접촉 팀의 상대가 체크볼한다. 공격 시간 초과도 소유권을 넘긴다.
- 경기 시간 종료 전에 릴리즈된 슛은 결과까지 판정한 뒤 종료/연장을 결정한다.
- 체크볼 중 경기 시간과 공격 시간을 멈춘다. 재개 패스가 유효하게 잡히면 두 시계를 시작한다.
- 초기판은 복잡한 자유투·개인 파울 누적을 생략한다. 접촉은 충돌과 동작 실패로 표현하며 이 규칙을 안내에 명시한다.

## 4. 작화 방향

**2D 그림처럼 읽히는 3D 캐릭터와 코트**를 사용한다. 팔·다리와 운동화의 실루엣을 강조하고 포즈가 작은 화면에서도 구분되어야 한다.

| 요소 | 제작 지침 | 확인 기준 |
| --- | --- | --- |
| 캐릭터 | 가드는 낮고 날렵한 자세, 포워드는 긴 팔과 균형, 센터는 넓은 어깨와 묵직한 착지 | 장식 없이 실루엣만 봐도 역할 구분 |
| 재질 | 2~3단 명암, 얼굴·옷의 큰 색 면, 절제된 하이라이트 | 정지 화면에서 입체감과 만화 느낌 공존 |
| 외곽선 | 캐릭터 위주 메시 확장 방식부터 시험. 거리에 따른 두께 변화 제한 | 여섯 명 겹칠 때 검은 덩어리가 되지 않음 |
| 코트 | 페인트 바닥, 철망, 벽화, 오래된 백보드. 장식 대비는 선수보다 낮게 | 공과 발 위치, 라인이 먼저 보임 |
| 색상 | 햇빛의 따뜻한 바닥, 청록/보라 계열 그림자, 팀별 밝기·패턴 차이 | 팀 구분이 색만으로 결정되지 않음 |
| UI | 굵고 읽기 쉬운 글자, 짧은 효과 문구, 얇은 상단 점수판 | 화면 중앙과 골밑을 가리지 않음 |

초기 카메라는 코트 전역이 보이는 사선 위쪽 시점이다. 직교와 약한 원근을 비교한 뒤 하나를 고정한다. 공을 따라 크게 회전하지 않는다. 골대·캐릭터 가림은 카메라 각도, 백보드 부분 투명 처리, 바닥 표식으로 해결한다.

웹 저사양 모드에서는 외곽선과 동적 그림자를 줄여도 체형·색 면·포즈로 작화가 유지되어야 한다.

## 5. 손맛과 연출

- **이동:** 짧은 가속과 명확한 정지. 방향을 바꾸면 발 딛기와 몸 기울기가 따라온다. 긴 애니메이션 블렌딩 때문에 입력이 늦어지지 않게 한다.
- **드리블:** 공이 손과 바닥 사이를 오가되 소유권은 플레이어에 고정한다. 매 바운스마다 자유 물리 충돌로 소유자를 다시 정하지 않는다.
- **돌파:** 방향 전환에 짧은 준비와 회복을 두고, 잘못 읽은 수비가 공간을 내주는 구조로 만든다. 버튼 연타가 항상 유리하지 않게 한다.
- **슛:** 준비→점프→릴리즈→착지의 실루엣을 구분한다. 골밑·중거리·외곽 슛의 동작과 호흡이 달라야 한다.
- **패스:** 버튼 입력에 즉시 준비 동작이 시작되고, 손을 떠나는 프레임에 공이 분리된다. 받는 선수는 캐치 후 다음 동작으로 부드럽게 이어진다.
- **블록:** 거리·방향·공 높이·유효 시간창이 맞아야 성공한다. 실패한 점프에는 착지 회복이 있어 페이크가 의미를 갖는다.
- **리바운드:** 위치 선점, 점프 타이밍, 도달 높이를 함께 평가한다. 공중에서 순간 이동하거나 센터가 자동으로 얻지 않는다.
- **효과:** 바운스·신발 마찰·림·스위시·블록 소리를 구분한다. 덩크는 짧은 카메라 충격과 림 반동을 사용하고 강도 조절을 제공한다.

온라인에서 연출 때문에 경기 전체 시간을 멈추지 않는다. 슬로모션이나 과한 카메라 확대는 우선 결과 화면에만 적용한다.

## 6. 조작 제안

기본 키는 방향키 + A/S/D/W로 잡고, 재지정을 제공한다. WASD 이동 프리셋은 행동을 J/K/L/I로 옮겨 충돌을 피한다.

| 입력 | 공격 | 수비 |
| --- | --- | --- |
| 방향키 | 이동·드리블 방향 | 이동·자리 잡기 |
| S | 방향에 가까운 동료에게 패스, 공이 없으면 패스 요청 | 스틸 |
| D | 누르면 슛 준비, 커밋 전 짧게 떼면 페이크, 유지하면 슛 | 슛 상황에서는 블록, 리바운드 가능 상황에서는 리바운드 점프 |
| A | 방향 전환 드리블 | 낮은 자세로 견제 |
| W | 공이 없을 때 스크린 | 루즈볼/리바운드 상황의 박스아웃 |
| Q / E | 두 동료 중 패스 수신자를 명시 선택 | 초기에는 사용하지 않음 |
| Esc | 오프라인 일시정지·설정 | 온라인에서는 메뉴만 열고 경기는 지속 |

슛 준비의 페이크 가능 구간은 약 0.15초에서 시작해 시험한다. 커밋 이후 입력 해제로 슛을 취소할 수 없다. 첫 버전은 별도 게이지 맞추기를 필수로 하지 않는다. 레이업/덩크는 거리·진입 속도·역할·수비 상황에 맞춰 D의 동작이 달라지고, 연습장에 발동 조건을 보여준다.

모바일은 가로 화면 기준으로 왼쪽 스틱, 오른쪽 주요 행동 3개와 보조 버튼을 배치한다. 세로 화면에도 공통 메뉴는 유지하고 경기 진입 전에 가로 전환을 안내한다. 모바일에서 블록/리바운드 자동 문맥 선택이 오작동하지 않는지 별도 검증한다.

## 7. 판정의 원칙

슛 성공률은 역할·거리·발의 안정·수비 압박을 입력으로 사용하는 조정 가능한 테이블로 만든다. 좋은 위치와 열린 슛이 유리해야 한다. 초기 가설은 적정 거리의 열린 슛 65~85%, 강한 방해 아래 15~35% 범위이며, 실제 적용값은 반복 시험으로 정한다. 이는 원작 수치가 아니다.

슛 시작 시 득점을 확정하지 않는다. 릴리즈 때 슛 조건과 궤적 후보를 결정한 뒤, 비행 중 유효한 블록·접촉을 반영한다. 최종 득점은 권위 시뮬레이션에서 공이 림의 득점 영역을 위에서 아래로 통과할 때 한 번만 기록한다.

스틸에는 손이 닿는 범위와 회복 시간이 필요하다. 리바운드는 먼저 유효 도달한 선수를 기준으로 하고 동일 틱 후보는 거리·행동 시작 시각 등 명시한 타이브레이커로 하나만 선택한다. 판정 결과와 근거를 개발 로그에 남긴다.

## 8. 최소 아트 제작 목록

- 동일 규격의 휴머노이드 리그 1종, 역할별 체형 3종, 팀 구분 색/패턴 2세트.
- 대기, 달리기, 정지/방향 전환, 좌우 드리블, 패스/캐치, 슛 준비/릴리즈/착지, 페이크, 레이업, 덩크, 수비 이동, 스틸, 블록, 리바운드 캐치, 박스아웃, 스크린.
- 공·골대·반코트·철망·배경 벽, 짧은 충격/스피드/착지 효과.
- 바운스·발 마찰·패스·림·스위시·블록·덩크·휘슬 효과음과 오리지널 짧은 루프 음악.

제작 순서는 대표 캐릭터 한 명을 끝까지 완성한 뒤 체형을 확장한다. Blender 등의 원본→glTF/GLB→Godot 파이프라인을 고정하고, 손·공 접점과 발 미끄러짐을 먼저 교정한다. 이미지 한 장의 인상만으로 애니메이션 품질이 확보된 것으로 판단하지 않는다.


## v0.2 구현 반영: 골밑 마무리와 릴리즈

같은 슛 입력 D/터치 버튼이 위치와 진입 속도에 따라 점프슛·레이업·덩크로 분기한다. 입력 시작 시 속도를 보존하여 준비 동작의 감속 때문에 덩크가 취소되지 않게 한다. 2.6m 이내는 레이업, 1.95m 이내·골대 방향 속도 2.7m/s 이상·중앙 폭 ±1.35m는 덩크다. 골대 뒤는 일반 슛으로 제한한다.

준비 → 도약(공을 손에 유지) → 릴리즈 → 비행/블록 → 득점/리바운드 → 착지 순서다. 덩크도 타이밍에 맞는 블록과 경합 실패가 있으며, 골밑 기술은 2점이다. 0.36~0.50초에 D를 놓으면 성공 확률에 8%p를 더한다(최대 99%). 짧은 페이크와 계속 눌렀을 때의 자동 슛은 유지한다.

시각 방향은 굵은 외곽선, 각진 저폴리 실루엣, 작은 얼굴, 넉넉한 유니폼과 비대칭 슬리브·레깅스, 큰 스니커즈다. 무릎과 골반의 낮아짐, 크로스오버 손 전환, 한 발 레이업, 한 손 덩크, 손목 팔로스루를 절차적으로 표현한다. 향후 원본 리깅 모델과 수작업 애니메이션으로 이 동작 계약을 대체할 수 있다.


## v0.3 아트 방향 정정 — 사용자 첨부 화면 기준

v0.2의 큰 머리·굵은 팔다리·과장된 신발과 선명한 민트 유니폼은 사용자가 기억하는 초기 프리스타일의 작화와 달랐다. 첨부된 코트 화면을 새 시각 기준으로 삼는다. 핵심은 작은 머리와 길고 가는 사지, 성인 비율, 날렵한 얼굴, 길게 떨어지는 티셔츠/저지와 카고 반바지, 차분한 스트리트 의상이다. 툰 외곽선 자체만으로 스타일을 맞췄다고 판단하지 않는다.

현재 구현은 약 7등신, 좁은 손·발, 긴 하체, 연속 단면으로 만든 옷·얼굴 메시와 낮은 채도의 의상이다. `street_model.gd`는 얇은 윤곽과 의상 표면 재질을 담당한다. 확대 보기에는 플레이에 쓰는 같은 모델을 사용한다. 향후에는 캐릭터별 비대칭 실루엣, 손으로 그린 얼굴·의상 텍스처, 관절 변형이 자연스러운 리깅과 애니메이션을 보강해야 첨부 화면의 아트 품질에 더 가까워진다.

## v0.4 수정 — 비율과 드리블 종료

코트 바깥 선은 폭 15m, 깊이 14m로 맞춘다. 28×15m 전체 코트의 절반에 해당하는 비율은 [FIBA 코트 자료](https://www.venueguide.fiba.basketball/vanue-design)를 참고했다. 실제 플레이 경계는 x ±7.5, z -7.225~6.775다. 골대 중심을 기준으로 3점 호 6.75m, 코너 직선 6.6m, 페인트존 4.9×5.8m, 자유투 원 반지름 1.8m를 사용한다. 선을 그리는 위치와 득점·클리어 판정을 같은 좌표계로 통일했다. 모든 경기 규칙을 FIBA와 동일하게 구현한 것은 아니다.

선수는 약 2m, 공 지름 .25m, 림 지름 .46m로 상대 크기를 정리했다. 얼굴·의상은 사진 질감 대신 그린 셀 명암으로 통일한다. 다리 길이와 발목 연결 위치를 기준으로 보행을 계산하며, 달리기 시작 시 다리가 과도하게 늘어나지 않도록 첫 발의 위상을 별도로 맞춘다. 지면에 닿은 발은 고정하고 공중에 있는 발만 다음 착지점으로 이동한다.

드리블 중 두 손으로 공을 잡는 `gather`에서 `dribble_ended`를 설정한다. 짧게 눌러 페이크가 되어도 해제하지 않는다. 이후 공은 두 손 사이에 머물고 바운드와 소리를 멈춘다. 방향키는 고정한 피벗 발을 중심으로 방향을 바꾸며 이동·크로스오버는 차단한다. 슛은 계속 가능하다. 새 체크볼·리바운드·스틸로 공격권을 얻을 때 드리블 가능 상태로 초기화한다. 현재 1대1 시제품에서는 패스가 없다.

## v0.5 수정 — 첨부 코트 구도와 고정 길이 관절

실제 코트 치수만 맞추고 평행 투영을 유지한 v0.4는 사용자가 제공한 경기 화면과 화면상의 비율이 달랐다. 경기 카메라는 `(0, 10.8, 12.8)`에서 `(0, 0, -2.8)`을 보는 원근 투영으로 전환한다. 화면비에 따라 시야각을 조정하고, 골대 쪽 기본 구도에서 가까운 경계로 이동하면 부드럽게 추적한다. 실제 이동·슛 판정에 쓰는 코트 좌표는 그대로 유지한다. 확대 확인 화면만 평행 투영을 사용한다.

관절의 도달 범위를 넘어갈 때 뼈를 늘려서는 안 된다. 허벅지 .51, 종아리 .49, 상완 .42, 팔뚝 .40 모델 단위를 유지하며, 발/손 목표를 도달 범위로 제한한 후 관절을 계산한다. 크로스오버에서 고정된 뒷발이 뒤에 남으면 접지를 풀고 짧게 회수한다. 공중에 있는 발의 착지점은 변경된 이동 방향을 따라 갱신한다. 무릎을 계산한 뒤 발만 다시 움직이는 보정은 금지한다.

캐릭터 확대 화면에서 대기·달리기·크로스오버를 전환한다. 미리보기에서는 같은 모델의 실제 `animate` 계산을 실행하고 이동량을 원점으로 돌려 제자리에서 보이게 한다. 애니메이션용 별도 가짜 모델은 사용하지 않는다.

### v0.6 발 순서와 드리블 확장

개별 발의 독립 재접지 이벤트를 제거하고 한 번에 한 발만 스윙하도록 공용 순서 관리기를 사용한다. 출발 첫 보폭은 짧게, 이후 보폭과 착지 예측은 이동 속도에 비례한다. 상체 위상은 실제 스윙 진행에 연결한다. 턴과 투스텝은 각각 0.64초이며 손으로 잡는 gather 상태에 들어가지 않는다. Z는 바깥손 드리블과 회전, C는 두 번의 측면 방향 전환이다. 기존 이동 경계·충돌·공격 제한·공 소유권·드리블 종료 제약을 그대로 적용한다. 기술 재입력은 현재 동작 종료 뒤 허용한다.


### v0.6.1 연속 동작과 수비 반응

비하인드 백은 원래 손의 밀기와 반대 손의 받기를 바운스 전후로 나눈다. 레이업은 반대발 도약과 슈팅 손 쪽 무릎 상승, 덩크는 뒤로 접는 다리와 림 목표 손 위치를 사용한다. 두 마무리의 루트 이동은 릴리즈 시점에서 속도가 연속인 Hermite 곡선으로 연결하며, 착지 때 접지를 새로 잡는다. 달리는 골밑 개더는 0.20초와 최대 두 번의 새 디딤으로 제한한다.

수비 페인트 반응은 거리 0.75~2.6m, 시선, 현재 관성 및 0.85초 재반응 제한에 따른 0.15~0.28초의 잘못된 방향 디딤이다. 기술 버튼 자체로 수비를 멈추지 않는다. 정면 접촉은 파고드는 속도만 제거하고 옆 방향 속도를 보존한다. 공중 선수와 지상 선수의 수평 밀어내기는 적용하지 않는다.


### v0.6.3 레이업의 마지막 디딤과 박스아웃

달리는 레이업은 개더 진입 속도의 86%를 이어받고 추가 웅크림을 줄인다. 지지 발끝은 월드 위치에 고정하고 뒤꿈치가 0.60rad까지 들리며, 0.12초의 신전 끝에서 수직 속도 약 4.46m/s가 0.78m의 포물선 점프로 연속해서 이어진다. 신발 자세는 상체 기울기와 독립적으로 월드의 접지 방향을 유지한다. 도약 후에는 지지 다리를 뒤로 회수하고 반대 무릎을 올린다.

박스아웃은 flight/loose 중 W 유지와 안쪽 위치가 필요하다. 상대가 뒤 0.30~1.25m 범위에 있고 림 또는 공 쪽을 가로막으면 활성화한다. 접촉 간격 0.95m와 자세 유지 가중치로 상대의 정면 진입을 막고, 뒤에서 몸을 통과하는 리바운드 획득을 제한한다. 측면 탈출, W 해제, D 점프, 새 소유권으로 해제된다. AI와 연습장의 박스아웃 위치도 같은 상태와 충돌을 사용한다.


### v0.6.4 접촉 자세와 낮은 수비

W 수비는 상대를 바라보는 방향을 유지한다. 수비/박스아웃/압박을 각각 완만한 가중치로 전환하고, 수비 발은 3.5cm 안팎의 낮은 높이와 짧은 보폭으로 이동한다. 움직이는 쪽 발부터 열고, 뒤따르는 발은 지지 발을 넘지 않도록 착지점을 제한한다. 정지 중에도 한 발씩 스탠스를 넓힌다.

박스아웃의 몸 방향은 상대에게서 멀어지는 방향, 고개는 공 쪽이다. 상대의 거리와 진입 속도로 압박을 계산하여 골반 하강·뒤로 싣기, 어깨 반대 기울기, 굽힌 팔의 접촉 위치를 조절한다. 접촉 폭은 기존 0.7m에서 자세에 맞춰 최대 0.86m로 점진적으로 넓혀 진입 시 위치 튐을 줄인다. 뒤의 상대도 접촉 자세를 취하고, AI는 0.25초 이후 측면 탈출을 시도한다.

### v0.6.5 낮은 수비의 접지와 옆걸음

수비는 일반 달리기와 별도 발 순서를 사용한다. 움직이는 쪽 발을 먼저 열고, 한 발이 착지한 뒤 약 18ms의 짧은 양발 접지 구간을 두고 뒤따르는 발을 회수한다. 발은 약 2.6cm만 들고 착지 진행 65% 이후 목표가 몸을 따라 움직이지 않도록 고정한다. 급반전의 선행 발 선택은 의도한 이동 방향의 변경을 기준으로 하며, 지지 때문에 몸이 잠시 감속해도 같은 발을 다시 선택하지 않는다.

몸의 실제 이동량은 접지 박자의 작은 감속·밀기에 연결한다. 지지 다리가 도달할 수 있는 범위 밖으로 몸이 먼저 나가지 않도록 제한하고, 회전·압박으로 필요한 여유는 무릎을 조금 더 굽혀 만든다. 접지 발을 움직여 과신전을 숨기는 상황을 줄이며 허벅지·종아리 길이는 그대로다. 사용자 W 수비, AI 낮은 수비, 박스아웃이 같은 이동 함수를 사용한다.

### v0.6.6 리바운드와 블록 동작 분리

D의 목적은 경기 상태로 구분한다. 박스아웃·루스볼·내 슛 또는 후반 비행 중에는 rebound, 상대의 슛 준비·도약·초기 비행에는 block을 시작한다. 두 동작은 0.10초 준비 디딤 후 0.62~0.66m 높이의 포물선으로 도약하고, 약 0.68~0.76초에 착지한 뒤 0.16초 동안 무릎으로 충격을 흡수한다. 준비 자세의 골반 높이를 이어받고, 지지 발의 월드 좌표와 다리 길이를 보존한다. 수평 이동은 출발 관성과 공 방향을 합쳐 약 0.47m 이내로 제한한다.

리바운드 손은 현재 공의 위치를 향한다. 손 사이 중심에서 0.29m 이내에 접촉해야 공중 캐치가 된다. 공과 손의 이전·현재 상대 경로도 검사해 낮은 업데이트 빈도에서 통과를 줄인다. 캐치 후에는 공을 가슴으로 0.20초 동안 당기고 착지가 끝날 때까지 바운스하지 않는다. 소유권은 즉시 확정하지만 점프 상태는 유지하며 새 D 입력도 착지 전에 슛으로 바뀌지 않는다. 착지 뒤 첫 드리블에는 짧은 연결을 둔다. 지상 자동 획득은 낮은 공과 0.52m 이내의 idle 상태에 한정한다.

블록은 공 쪽 한 손을 위로 뻗고 반대 팔로 균형을 잡는다. 유효 시간 0.13~0.52초와 손·공 접촉 0.31m가 모두 필요하다. 접촉 뒤 손이 튕겨 나가는 공을 계속 쫓지 않도록 목표를 고정하고 손목을 내린다. 공은 충돌 방향과 손 방향으로 튕기며 한 번만 루스볼로 전환된다. 미스 블록은 그대로 착지하여 다시 수비한다. 기존 득점·클리어·박스아웃·단일 소유권 규칙을 함께 사용한다.

연습장에는 리바운드 캐치와 블록 타이밍 버튼을 둔다. 후자는 레이업 진입이 아닌 제자리 점프슛으로 두 선수가 겹치지 않게 한다. 느리게 연습에서는 캐치는 정면, 블록은 측면에서 확인한다.

### v0.6.7 경기 중단과 재개

창을 벗어나거나 문서를 숨기거나 조작법·업데이트를 열면 지속 정지 요청을 보낸다. 다른 설정 명령이 정지 요청을 덮지 못한다. 안내창을 닫아도 경기는 멈춰 있으며 계속 플레이에 초점을 돌려 직접 재개한다. 중단한 제자리 슛 준비는 드리블이 끝난 공 보유 상태로 정리하여 외부 keyup이 슛이나 페이크로 해석되지 않게 한다. 이미 진행 중인 마무리·리바운드·블록은 공과 동작 상태를 보존한 채 이어간다.

중단 시 키·터치·스틱 상태를 해제하고 이전 키의 repeat만으로 재시작하지 않는다. 엔진도 재개 직후 입력이 한 번 중립이 될 때까지 이전 held 동작을 받지 않는다. 효과 줄이기는 일시정지 중에도 궤적·충격 표시와 UI 전환에 반영하되 공·득점 계산을 바꾸지 않는다. 설정은 부팅 때 덮어쓰지 않고 사용자가 바꾸었을 때만 저장하며 실패 시 현재 창에서 적용 중임을 알린다.

### v0.6.8 접촉 순간과 착지의 동작 연결

리바운드 접촉은 손 목표를 즉시 가슴으로 바꾸지 않는다. 실제 두 손의 월드 위치와 공의 들어오는 속도를 캐치 시 저장한다. 초기 70ms의 감쇠 이동으로 손이 충격을 받아내며, 올라가는 몸통에 대해 팔꿈치가 접힌다. 55ms부터 260ms까지 가슴 앞 보호 자세로 당긴다. 공은 렌더된 두 손의 중심을 따라간다.

블록은 실제 접촉 시각과 손 위치를 기준으로 약 85ms의 짧은 쳐내기를 시작한다. 이후 240ms까지 팔꿈치를 접고 440ms에 균형 자세로 회수한다. 손목도 같은 접촉 시간을 사용하며 절대 애니메이션 시각에 맞춰 미리 꺾지 않는다. 반대 팔은 균형을 잡는다. 쳐낸 공에는 아래 방향 속도를 주고 루스볼 규칙으로 연결한다.

첫 발 접촉은 기존 도약 종료 시각에 맞추고, 반대 발은 45ms 뒤에 닿는다. 발끝을 축으로 기울어진 신발이 55ms에 걸쳐 뒤꿈치를 내려놓는다. 첫 접촉 이후 95ms 동안 골반이 약 -0.22m까지 내려가며 하강 속도를 흡수한 뒤, 260ms에 보유/수비 대기 높이로 돌아간다. 그 전까지 고정되는 발끝의 월드 위치와 신발 회전을 함께 계산한다. 공중 다리는 같은 고정 포즈 대신 좌우 회수량을 다르게 하고, 착지 쪽으로 작은 체중 이동과 상체 숙임을 연결한다. 리바운드/블록 전체 회복 시간은 각각 약 1.02/0.94초다.


### v0.6.9 착지에서 다음 걸음으로

리바운드·블록은 첫 발 접촉 뒤 95ms의 무릎 압축과 양발 뒤꿈치 접지를 유지한다. 이동 입력이 있으면 첫 접촉 약 115ms 뒤부터 실제 신발 위치를 지지점으로 인계한다. 먼저 착지한 발을 남기고 반대 발이 160ms의 짧은 걸음으로 열린다. 이동 속도는 200ms 동안 정상 속도로 회복하며, 지지 다리의 도달 범위 안에서만 몸을 밀어낸다. 입력이 없으면 기존 제자리 착지 회복을 마친다.

골반은 동작 종료 때 고정 대기 높이로 바꾸지 않는다. 렌더된 높이와 수직 속도를 이어받아 임계 감쇠로 현재 보행/정지/낮은 수비 자세에 접근한다. 지지 발 교대 때 남아 있는 무릎 굽힘도 즉시 풀지 않는다. 상체 기울기와 손의 공 보호를 함께 연결하며, 공중 캐치 동안의 드리블 정지와 착지 후 드리블 연결을 유지한다. 플레이어·AI가 같은 인계 경로를 쓴다.


### v0.6.10 앞꿈치 밀어내기와 달리기 진입

착지에서 보행으로 인계한 뒤 첫 두 걸음을 실제 접지 진행도로 추적한다. 첫 지지 발은 앞꿈치를 월드 공간에 고정한 채 최대 0.32rad까지 뒤꿈치를 들어 올린다. 신발 회전과 발 위치의 피벗 보정을 함께 적용하며, 다리 길이 제한과 지지 무릎 압축도 실제 접촉 위치를 사용한다. 이후 그 발을 떼는 스윙 초반에 신발 기울기를 푼다.

첫걸음은 약 180ms, 두 번째는 160ms를 기준으로 받는다. 첫 보폭의 후반 68%부터 착지 목표를 고정해 가속하는 몸통을 발이 계속 쫓지 않게 한다. 다음 발 접지 뒤에는 이전 지지 발의 스윙을 이동 계산 전에 시작하여 양발 제동 틱을 없앤다. 속도는 첫 밀어내기에서 정상 속도의 18→43%, 두 번째 접지 과정에서 43→100%로 연결한다. 정지·반전 입력은 계속 반영한다.

골반은 밀어내는 구간에 낮은 착지 높이에서 상승하고 다음 발이 받는 구간에 다시 굽혀 달리기 자세로 연결한다. 실제 속도가 한 프레임 줄었다고 골반이 갑자기 펴지지 않도록 두 걸음의 목표 높이와 기존 수직 감쇠 회복을 함께 사용한다. 상체는 이동 방향으로 기울고 첫 지지 쪽 체중 이동은 짧게 생겼다가 해제된다. 제자리 착지와 일반 낮은 수비의 기존 접지 규칙은 유지한다.


### v0.6.11 보폭·상체·팔의 같은 접지 박자

첫 두 밀어내기 다음에는 별도의 달리기 위상으로 갈아타지 않는다. 같은 발 교대의 진행도를 네 걸음까지 추적하며 전방 발 목표 범위를 0.28→0.64m, 발 들기 높이를 0.065→0.14m로 점진적으로 연결한다. 일반 달리기에서도 스윙 68% 이후 발 목표를 확정하여 접지 직전 몸을 따라 목표가 계속 움직이지 않게 한다. 수비 옆걸음과 드리블 기술은 각각의 접지 규칙을 유지한다.

기존 팔 진자는 다리 스윙 중간에 최대가 되고 발 접촉 때 중립으로 돌아갔다. 새 박자는 실제 발 교대의 시작/종료에서 앞뒤 팔이 교차 극점에 있고, 다리가 스칠 때 팔도 중립을 지난다. 어깨 비틀림은 손과 같은 감쇠 속도로 따라가며, 첫 네 걸음과 실제 속도에 맞춰 흔들림의 크기를 점진적으로 늘린다. 공을 가진 손의 드리블·보호 동작은 기존 전용 자세를 유지한다.

몸통은 발을 디딜 때 낮아지고 다리가 스치는 구간에 조금 올라가며, 지지 방향의 작은 좌우 체중 이동과 달리는 방향의 기울기를 더한다. 착지의 높이/속도 연속성, 앞꿈치 밀어내기와 고정 길이 IK는 유지한다.


### v0.6.12 달리기의 제동과 방향 전환

일반 지상 이동에서 2.2m/s 이상으로 달리다 이동을 놓거나 입력이 진행 방향에서 크게 벗어나면, 독립된 시간 지연 대신 실제 제동 발 접촉을 사용한다. 이미 스윙 중인 발 또는 다음 교대 발을 제동 발로 선택하고 현재 위상/위치를 유지한 채 남은 착지 시간을 최대 약 70ms로 줄인다. 발은 이전 진행 방향 앞에 내려놓고, 닿은 뒤 약 65ms 이상의 무릎/골반 압축으로 관성을 받아낸다.

하중을 받는 동안 발의 월드 접지를 고정하고 몸은 이전 방향을 유지한다. 멈출 때는 약 140ms의 안정화 뒤 제동 상태를 끝내며 무릎을 천천히 편다. 새 방향 입력이 있으면 반대 발의 짧은 스윙을 시작하고 지지 앞꿈치로 밀어낸다. 이때부터 몸통 회전을 허용하며 회전 속도를 제한한다. 이후 기존 첫 네 걸음의 보폭/팔 동조로 이어진다.

이동 입력은 매 틱 갱신되므로 제동 중에도 새 방향을 선택할 수 있다. 공을 두 손으로 든 상태, 도약/마무리, 드리블 기술, 낮은 수비/박스아웃은 기존 전용 규칙을 우선한다. AI와 플레이어의 일반 이동은 같은 함수를 사용한다.


### v0.6.13 방향 전환 뒤 받기·재차 밀기·보폭 확대

방향 전환 후 첫 반대 발이 닿아도 제동 동작을 바로 종료하지 않는다. 받기 상태에서 새 지지 발로 체중을 옮기고, 이전 지지 발을 다음 스윙으로 해제한다. 첫발 약 170ms, 다음 두 걸음 약 160ms를 기준으로 실제 교대 진행도를 추적한다. 각 구간의 목표 속도는 정상 속도의 20→50→80→100%이며 중간 입력도 계속 반영한다.

발의 착지 축은 이전 몸 방향에서 새 진행 방향으로 두 걸음 동안 돌아간다. 발 목표는 새 방향의 예상 이동과 받기 이후 밀어낼 여유를 반영하며, 전방 목표 상한을 약 0.24→0.70m로 단계적으로 넓힌다. 고정 길이 다리의 지지 범위 안에서만 뿌리가 움직이며 후반 발 목표는 기존처럼 확정한다.

각 지지 발은 앞꿈치 접촉을 보존하면서 최대 약 0.30rad까지 뒤꿈치를 들어 다음 보폭으로 밀어낸다. 두 번째 받기 뒤 세 번째 걸음까지 작은 압축을 유지하여 골반이 먼저 펴지면서 발이 끌리거나 재가속이 끊기지 않게 한다. 골반의 좌우 이동 기준은 실제로 바닥에 남은 발이며, 지지 교체 시 목표를 부드럽게 보간한다. 이후 기존 네 걸음의 팔/보폭 동조로 연결한다.


### v0.6.14 한 손 스틸과 전진 디딤

S 입력 시 소유권을 즉시 바꾸지 않는다. 상대를 보는 방향으로 간격을 계산해 최대 0.38m의 짧은 전진을 25~230ms에 수행하며, 지지 다리의 도달 범위와 선수 몸 충돌로 제한한다. 무릎을 굽혀 골반을 낮추고 상체를 앞으로 기울이며 공 쪽 손을 선택해 뻗는다. 반대 손은 뒤에서 균형을 잡는다.

상대 드리블을 먼저 갱신해 현재 공 위치로 손을 조준하고, 120~320ms의 실제 손-공 접촉을 상대 운동의 스윕 거리로 검사한다. 초기 거리/방향과 상대의 드리블 가능 상태가 유효하고 손이 공에서 0.25m 이내여야 기존 65% 성공 판정을 한 번 수행한다. 멀리 있거나 등을 보거나 이미 슛에 들어갔으면 공을 가져오지 못한다.

성공하면 실제 손 위치와 공 오프셋을 저장하여 손에 붙여 바깥 골반으로 당긴다. 동작 중 드리블 위상을 멈추고 600ms의 회복 종료 뒤 200ms에 걸쳐 정상 드리블로 연결한다. 실패하면 손과 팔꿈치를 회수하며 낮은 전진 자세에서 균형을 되찾는다. 새 소유권의 드리블 권리와 1대1 외곽 클리어 규칙을 보존한다. 스틸 파고들기 연습은 상대가 공을 유지하며 느린 측면 시점에서 반복한다.


## v0.6.15 · 손바닥 블록과 공중 양손 캐치

- 블록 준비는 팔꿈치를 들어 공 위로 손을 뻗고, 접촉한 실제 월드 손 위치에서 140ms 동안 아래 0.43m·앞 0.23m 방향의 후속 궤적을 만든다. 고정 길이 팔 IK를 유지하며 손목 굽힘과 몸통 회전으로 힘 전달을 보인다. 이후 팔꿈치를 접어 균형을 회복한다. 빗나가면 기존 공 추적/회수 경로로 복귀한다.
- 성공 판정은 기존 실제 손-공 상대 이동 경로 검사와 130~520ms 창을 유지한다. 성공한 공은 아래 방향 3.6m/s로 쳐내며 루즈볼로 이어지고 중복 블록/득점을 막는다.
- 리바운드는 열린 양손이 공 양옆으로 모이고, 두 손 모두 공에서 0.34m 이내·중심 경로 0.24m 이내·점프 높이 0.18m 초과일 때 공중 캐치한다. 몸 근처의 높은 공을 자동으로 가져오는 판정은 없다.
- 캐치 후 35ms 동안 공의 속도를 손으로 짧게 받아내고, 머리 위 확보 자세를 거쳐 200~430ms에 걸쳐 가슴으로 당긴다. 늦은 캐치도 착지 회복 완료 전 보호 자세로 수렴한다. 공은 실제 두 손 중간에 고정하며 착지 전 드리블 위상을 멈춘다.
- 머리는 공을 올려다본 뒤 보호 자세와 함께 돌아온다. AIR CATCH/SECURED와 짧은 손-공 접촉음으로 바닥 바운스와 구별한다. 기존 앞꿈치 접촉·무릎 압축·첫걸음 연결을 유지한다.
- 느린 리바운드 연습 카메라는 골대 뒤 구조물을 피한 코트 측면에서 공·두 손·발을 함께 보여준다. 자유 연습/1대1의 판정과 애니메이션은 같은 코드를 쓴다.

## v0.6.16 · 몸과 공의 타이밍

- 달리기: 실제 발 접촉 주기에서 상체 회전·좌우 기울기와 반대 팔의 전후 운동을 만든다. 골반은 작은 반대 회전으로 받치고, 팔꿈치를 굽혀 손을 끌어오는 궤적으로 변경한다. 수비/특수 기술/공중 동작은 각각의 기존 단계가 우선한다.
- 일반 드리블: 한 바운스의 0~20%에서 손바닥이 공 상단을 밀고, 이후 손을 회수한다. 72~94%에서 상승하는 공을 받아 다음 밀기로 이어진다. 바닥 접촉은 42%, 소리도 같은 박자다. 몸의 높이에 맞춰 공의 바닥 목표를 보정한다. 슛 준비로 두 손에 공을 잡았을 때의 재드리블 금지는 유지한다.
- 블록: 준비 손을 실제 현재 슛 손 위치 위로 먼저 올린 뒤 아래로 스윙한다. 구조화된 블록은 실제 손의 하향 속도와 0.28m 손-공 경로 접촉을 함께 검사한다. 접촉한 월드 손 위치와 속도를 기록해 후속 곡선으로 이어가며, 다시 정지 상태에서 가속하지 않는다. 준비 동작과 접촉 곡선에 중복 평활화를 적용하지 않는다. 매우 큰 프레임 속도는 제한해 접촉 후 팔의 위치가 튀지 않도록 한다.
- 리바운드: 잡기 → 정점 부근 양손 확보 → 하강 중 상체를 따라 가슴으로 당기기 → 보호 자세 착지. 당기기 진행도를 손·팔꿈치·손목·고개에 공유한다. 늦은 캐치는 충분한 회수 시간을 확보해 착지 회복 구간에서 보호 자세로 수렴한다. 기존 양발 시차와 무릎 충격 흡수를 유지한다.


## v0.6.17 · 달리기 어깨·팔꿈치·손목 연결

- 반대 팔은 발 접촉 주기의 어깨 회전각과 팔꿈치 굽힘각으로 목표 위팔/팔뚝을 구성하고, 몸통을 따르는 좌표에서 고정 길이 IK로 연결한다. 손끝 목표만 앞뒤로 왕복시키며 팔꿈치 방향을 뒤늦게 추측하던 경로를 줄인다. 진폭은 첫 걸음과 가속에 맞춰 늘어나고 짧은 평활화로 위치 급변을 막는다.
- 정상 달리기/일반 드리블에는 별도의 팔꿈치 굽힘 기준을 유지한다. 계산을 마친 관절을 다음 굽힘 기준으로 다시 사용하는 피드백을 피하고, 드리블 팔꿈치를 몸 가까이 둔다. 공중·수비·특수 기술은 기존 단계가 우선한다.
- 어깨 형태를 몸통의 고정 구체에서 움직이는 위팔의 연결부로 옮긴다. 반대 손목은 팔뚝의 연장 방향을 따르고, 드리블 손은 손바닥이 공 위를 향하게 한다. 엄지와 손목 밴드도 같은 손/팔 좌표를 따르며 다른 동작으로 넘어갈 때 잔류 회전을 비운다.
- 일반 드리블 공의 바깥/앞 위치를 0.58/0.43~0.53에서 0.54/0.38~0.44(모델 로컬 단위)로 조정해 밀기 말미의 최대 팔 뻗기를 줄인다. 기존 밀기·회수·받기 위상과 바운스 시점은 유지한다. 조정된 공 경로에서는 스틸 소유권을 옮기는 현재 틱에도 손이 0.25m 이내로 실제 닿아 있어야 한다.


## v0.6.18 · 기준 자세로 구성하는 크로스오버

기존 관절 수치 보정에서 벗어나 `scripts/crossover_clip.gd`에 여섯 기준 자세를 둔다. 속임 → 하중 → 강한 바운스 → 체중 이동 → 반대 손 받기 → 돌파의 실루엣을 먼저 구성하고, 실제 손-공 접촉과 고정 길이 IK를 제약으로 적용한다. 현재 구현은 기존 절차적 리그에 작성한 자세 데이터이며 외부 모션 캡처나 스킨 애니메이션으로 교체한 것은 아니다.

입력 순간 공·손 위치/방향·바운스 위상을 저장한다. 이미 내려가거나 올라오는 공을 새 궤적으로 순간 이동시키지 않고 기존 바운스를 이어 보내는 손에 도착시킨다. 핵심 전환은 380ms이며 그 전에 현재 바운스 회수를 기다릴 수 있다. 받는 손이 실제 공 상단에서 0.045m 이내에 도달해야 손 역할을 바꾼다. 이때 기존 제동/재출발 지지 발을 유지하고, 종료 후 160ms에 걸쳐 일반 드리블과 반대 팔 달리기로 복귀한다. 손목은 역할별 방향을 혼합하고 실제 월드 방향을 이어가며 최대 20rad/s로 제한한다.

사용자 참고 영상: [이렇게 스윙 되면 참 재미있는 게임 인데.. - 프리스타일2](https://www.youtube.com/shorts/9_V2DxLzFvY). 브라우저 재생과 연속 장면으로 이동/공격 자세를 확인했다. 낮게 깔린 이동 실루엣, 큰 팔·다리 동작, 방향 전환 시 몸 전체가 따라가는 연결을 후속 작업의 시각 기준으로 삼는다. 원본 애셋/모션을 추출하지 않는다. 이번 크로스오버 외의 모든 동작까지 같은 수준으로 완성됐다는 의미가 아니다. 달리기 전체의 기준 자세와 피부/의상 변형은 별도 보완 대상이다.


## v0.6.19 · 낮은 달리기와 컷 이후 돌파

`scripts/run_clip.gd`는 실제 발 교대 위상의 반 주기를 접촉 → 압축 → 통과 → 밀기 → 다음 접촉의 다섯 기준점으로 나눈다. 반대 팔과 상체는 같은 위상을 읽고, 드리블 손은 실제 공 경로가 우선한다. 기존 보행 순서/발 교대/고정 길이 관절 IK를 보존한다. 이는 현재 절차적 리그에 적용한 기준 자세 데이터다.

달리기 중 기본 골반을 추가로 약 0.075m 낮추고 접지별 작은 압축을 더한다. 상체 전경·어깨 회전과 반대 팔 흔들림을 확대하되 팔을 과하게 뒤로 젖히지 않는다. 일반 달리기의 지지 발도 공중인 반대 발의 진행도에 따라 최대 0.25rad의 뒤꿈치 들기를 수행한다. 실제 앞꿈치 위치를 기준으로 신발 위치/회전을 함께 보정해 상체 전경 때문에 발이 끌리지 않게 한다. 공중 발은 발끝을 회수하고 평평하게 착지를 준비한다.

컷의 제동 접촉 전까지 몸 방향을 유지하고, 하중을 받은 후 가슴과 몸통 기울기가 새 방향을 예고한다. 밀기 진폭은 재출발 세 걸음의 실제 진행도에 연동한다. 90도 컷의 첫 받기는 170ms, 180도 반전은 140ms이며 사이 각도는 부드럽게 보간한다. 반전에서 반대 발이 너무 늦게 내려가 기존 지지 발의 다리 도달 범위를 소진하는 문제를 방지한다. 원래의 짧은 첫 보폭 → 두 번째 받기 → 세 번째 달리기 보폭과 속도 증가는 유지한다.

몸통을 낮춰도 손바닥은 월드 아래 방향으로 공을 누른다. 가슴 전경을 그대로 손목에 더하지 않는다. 손 회수는 한 바운스의 20~48%에서 이뤄지며 다음 상승 공을 받는 위상은 유지한다. 참고 영상의 낮은 이동 실루엣과 전신 연결을 목표로 하지만 원작 모션의 복제나 모션 캡처 교체는 아니다.


## v0.6.20 · 지지 발을 유지하는 컷과 강한 블록

기존 컷 각도 문턱은 약53도로 30~45도 전환이 접지 처리를 건너뛰었다. 이제 25도 초과 방향 전환은 제동 접촉·하중 뒤 몸을 돌린다. `start_ground_step`으로 이동 전 다음 발을 해제하고, 일반 달리기로 돌아온 이후에도 지지 다리의 고정 길이 도달 범위를 적용한다. 루트 이동/무릎 압축으로 접지를 유지하며, 뒤처진 발을 새 위치로 끌어오는 도달 보정의 발생 원인을 줄인다. 초기화/텔레포트로 발 접점이 없으면 다음 animate의 기존 자세 초기화를 먼저 거친다. 첫 보행 주기는 최소120ms로 제한한다.

컷 하중에서는 반대 팔을 굽혀 몸통 가까이 받치고, 실제 재출발의 첫 받기 진행도에 따라 달리기 스윙으로 연다. 목표 손/팔꿈치 보간은 이전 가슴 좌표를 현재 가슴 좌표로 옮긴 뒤 수행한다. 드리블 손의 실제 공 접촉은 우선하며 자유 팔만 가슴 회전을 함께 따른다. 반대 손목은 느려져도 팔뚝 방향을 유지해 속도에 따른 인위적인 손목 꺾임을 없앤다.

사용자가 강조한 블록은 손바닥으로 공을 강하게 쳐내 궤도를 바꾸는 동작이다. 실제 손-공 접촉과 130~520ms 타이밍 창, 하향 스윙 조건을 만족할 때만 처리한다. 접촉 시 고정한 팔의 바깥/아래 스윙 벡터(로컬 손 쪽0.10, 아래0.50, 앞0.36)를 팔 후속 궤적과 공의 출사 방향이 공유한다. 공은 해당 방향으로9.2m/s의 속도를 받고 즉시 루즈볼이 된다. 팔은 접촉 위치/속도에서160ms 후속 동작을 이어 회수·착지한다. 공이 손에 붙거나 멈추는 연출은 없다. 기존 득점 중복 방지와 외곽 클리어 규칙을 유지한다. 이전 슛 잔상은 지우고 쳐낸 공의 궤적만220ms 표시하며 효과 줄이기에서는 숨긴다.


## v0.6.21 · 블록의 전신 동작과 실제 리바운드 경기 흐름

블록은 130ms까지 팔꿈치를 굽혀 손을 머리 위/뒤로 준비한 뒤150~280ms에 가슴과 어깨를 돌려 팔을 전방·아래로 휘두른다. 실제 손 목표가 공에 도달하고 하향 이동할 때만 기존 타이밍 판정을 적용한다. 접촉 시 실제 상체 회전을 저장해 후속 자세로 이어가며, 손바닥은 지면을 향하고 엄지/손목 밴드도 손과 팔 방향을 따른다. 별도의 새 시간축이나 타격 후 순간 자세 변경을 쓰지 않는다.

뒤쫓는 수비의 자동 블록 문제는 AI 의사결정과 실제 접촉을 나눠 처리한다. 헛디딤 회복 중에는 도약 결정을 하지 않는다. 수비가 공격수보다 골대 반대쪽으로 뒤처졌으면0.75m 이내 복귀 및 페인트 회복을 마쳐야 AI가 추격 블록을 시도한다. 실제 블록은 잠긴 도약 방향의 앞쪽이며 수평거리1.15m 이내여야 하고 손에서 공으로 가는 경로가 공격수 몸통을 통과하면 실패한다. 정면에서 자리를 잡은 수비나 실제 가까이 따라붙은 추격 블록은 가능하다. 돌파 성공이 무조건적인 블록 면역이 되지는 않는다.

기존 미스 슛 목표는 림 중심에서0.52m 떨어져 림 바깥에서 허공 바운스가 생겼다. 이제 목표는 림 둘레0.23m·상단+0.06m이며, 해당 접점의 앞/옆 방향으로1.2~1.9m/s, 위로3.9~4.5m/s의 반발을 준다. 림 접점과 상승/정점/하강이 보이는 동안 W로 자리싸움하고 D로 공중 캐치한다. 일반 슛·레이업 성공률 상한은94%, 덩크는99%다. 슛 미스를 매번 강제하지 않는다. AI는 약280ms 뒤의 낙하 높이/도달 거리를 보고 점프하고, 박스아웃에 막혔으면 먼저 측면 탈출을 시도한다.

최신 사용자 요청에 따라 포지션의 시험용 기본 밸런스만 먼저 구현했다. G/F/C는 이동속도4.7/4.4/4.0m/s, 리바운드 도약0.66/0.76/0.86m, 공중 이동 목표 한도0.34/0.48/0.28m, 박스아웃 버티기1.0/1.25/1.6이다. 가드는 이동, 포워드는 이동하며 경합, 센터는 골밑 높이·자리 유지가 강점이다. 손이 닿지 않은 공을 능력치로 가져오지 않으며 모델/팔다리 길이도 바꾸지 않는다. 라이벌 기본 프로필은 가드이며 이 수치는 최종 경쟁 밸런스가 아니다. 성장·스킬 육성/선수 저장은 별도 계획으로 유지한다.

림·박스아웃 경합 연습은 실제 상대 슛→림 미스→루즈볼/경합 코드를 사용한다. 연습에서 상대 슛만 미스로 고정하며 화면에 이를 명시한다. 일반 경기에서는 확률 결과를 바꾸지 않는다. 포지션은 경기 전/종료 후 또는 자유 연습의 지상 대기 상태에서만 변경하며 현재 세션에만 유지한다.


## v0.6.22 · 헛디딤에서 추격 달리기로

드리블 속임이 유효한 정면 수비에 들어오면 현재 공중 발을 마저 짧게 내딛는다. 이동 방향만 즉시 바꾸지 않는다. 실제 발이 내려온 뒤 최소100ms 하중을 받아 무릎과 골반을 낮춘다. 기존 제동·재출발 접지 스케줄러를 공유하며, 하중 전에는 루트 회전을 잠근다.

회복 회전은 지지 발의 앞꿈치 접점을 월드에 유지하며 신발 방향을 바꾼다. 반대 발은180ms의 작은 열기 보폭으로 새 방향을 받는다. 회전이 따라오고 반대 발이 내려와야 첫 밀기를 시작하며 이후 세 걸음의 실제 진행도에 맞춰 속도·보폭·팔 흔들림이 커진다. 상체 회전과 균형 팔은 기존 컷 자세에서 추격 달리기로 이어진다.

AI는 회복 중 낮은 수비 옆걸음을 해제하고 추격 목표를 바라본다. 공격수보다 뒤처진 동안에도 진행 방향으로 달리며, 골대 쪽 자리를 되찾으면 정면 수비로 복귀한다. 회복 중에는 블록 결정을 하지 않고, 도달 가능한 정상 추격 블록은 이전 접촉 기준을 유지한다. 진행 중인 회복에 속임을 중첩하거나 공격수 뒤에서 새 헛디딤을 시작하지 않는다. 공수 교대·새 경기에서는 회복 상태를 초기화한다.

돌파·수비 회복 연습은 동일한 크로스오버 입력과 수비 코드를 쓴다. 결과를 강제하는 별도 애니메이션 재생이 아니다. 세션·육성·모바일 범위는 기존 계획을 유지한다.

## v0.6.23 · 실제 경기의 스킨 리그

자유 연습/1대1의 양쪽 선수는 `RiggedStreetVisual`의 45본 스킨 메시를 기본 렌더링한다. 기존 `StreetPlayer`의 상태·규칙·물리 루트와 접지 스케줄러는 유지하되 이전 부품 메시를 숨긴다. 비교 페이지의 왼쪽만 명시적으로 이전 렌더링을 사용한다. 별도의 비교 장면에서만 새 모델을 보여주는 상태를 끝내고 실제 경기 입력과 연결했다.

평상시 이동은 원본 run/idle 전신 키프레임과180ms 클립 전환을 사용한다. 실제 이동 속도로 재생 속도를 정하며 반대 팔/골반/어깨/다리의 원본 위상을 유지한다. 원본의 체인 스케일은1로 고정해 팔다리가 늘어나지 않게 한다. 드리블 팔만 제한된 쇄골 회전과 두 뼈 IK, 아래를 향한 열린 손바닥으로 공의 밀기/받기 지점을 따른다. 원본 파일의 뼈/메시나 애니메이션 키를 수정한 것은 아니다.

발의 접점은 실제 발가락 뼈의 월드 위치다. 닿은 앞꿈치는 월드에 유지하고 뒤꿈치 방향/무릎 압축을 보정한다. 컷에서 길이가 다른 이전 리그의 접점 배열을 새 리그에 그대로 복사하지 않는다. 현재 새 리그 접점을 보존하면서 기존 스케줄러의 받기/밀기 의도를 사용한다. 실제 지지 다리의 도달 범위와 최대10cm의 골반 체중 이동으로 물리 루트의 과도한 전진을 막는다. 해제된 발은 다음 이동을 더 이상 제한하지 않는다.

방향 전환/수비 회복 뒤 원본 달리기로 돌아갈 때 현재 지지 발의 밀기 말기 위상에 클립 시간을 맞추고120ms 동안 직전 전신 포즈에서 전환한다. 서로 다른 발 박자에서 즉시 달리기로 바뀌지 않는다. 새 리그의 180도 첫 받기는100ms로 마쳐 지지 발 교환 중 재출발이 멈추지 않게 했다. 수비의 헛디딤 상태와 뒤처진 방향으로 돌아서 추격하는 AI 판단은 같은 경로를 사용한다.

스틸/블록의 `hand_world`, 리바운드 양손 접촉/보호 위치, 공을 양손으로 잡은 위치는 새 리그의 실제 손바닥에서 읽는다. 숨겨진 이전 손 위치는 특수 동작의 목표를 만드는 데 사용하며 판정 위치와 구분한다. 슛/레이업/덩크/스틸/리바운드/블록은 같은 스킨 메시로 기존 목표 동작을 이어 렌더링 교체를 하지 않는다. 이 동작들의 농구 전용 전신 클립을 모두 새로 제작했다는 뜻은 아니다.

외형은 GDQuest/기여자·Luciano Muñoz의 임시 마네킹에 경기용 색상을 적용한 것이다. 최종 얼굴/의상은 별도 제작이 필요하다. 실제 출처/CC BY 4.0 고지를 유지하고, 육성 기능과 모바일 실기기 검증 범위는 기존 계획을 유지한다.

## v0.6.24 · 사람형 얼굴과 농구복

화면용 마네킹 메시를 자체 제작 사람형 외형으로 바꿨다. 운동선수 비율의 피부 실루엣에 턱·광대·코·눈꺼풀·눈썹·귀·입·짧은 검은 머리를 형상으로 더한다. 피부에 독립된 로봇 관절 구가 보이지 않게 쇄골부터 위팔까지 연속 표면을 사용한다. 청록 07번/주황 23번 저지, 느슨한 반바지, 목둘레·암홀·옆 패널·밑단·원단 패턴·손목밴드·양말·농구화를 구성하며, 23번은 헤드밴드로 구별한다. 원작 게임 자산을 추출하지 않는다.

외형은 기존 45본 리그에 연결된 ArrayMesh다. 일반 달리기/드리블/컷·추격의 리그 동작과 실제 손바닥/발 접점을 유지한다. 옷과 저지의 인쇄 도형도 같은 가중치를 따라 변형된다. 약7.7천 삼각형·7개 재질 표면/선수를 현재 모바일 대비 형상 예산으로 사용하되 실기기 성능 검증과 최종 아트 승인으로 간주하지 않는다. 새 경기 로드부터 양쪽 선수에 기본 적용하며, 캐릭터 스튜디오는 진행 중인 경기와 별도로 확대/움직임을 검토하는 화면이다.

## v0.6.25 · 관절 안정성과 얼굴·의상 재제작

실제 경기의 역무릎, 새 접지 첫 프레임의 위치 덮어쓰기, 스윙 도중 상태 종료, 중복 이동 제한을 수정한다. 현재 디딤은 실제 발 위치를 보존하고 해부학적 방향으로 무릎을 굽히며, 자유 발은 예측 착지점으로 이동한 뒤 전신 클립으로 이어진다. 스틸 손은 낮은 공을 향해 손가락부터 뻗고 상체/어깨가 함께 숙인다. 접촉 거리와 판정 확률은 그대로다.

얼굴은 머리 크기/턱/광대/눈두덩/코를 성인 비율로 조정하고 자체 생성한 수작업풍 텍스처를 새 UV에 맞춘다. 어깨와 팔꿈치 형상을 다듬고, 저지는 허리와 겨드랑이에서 실제로 접히는 표면/법선을 사용한다. 바지는 무릎 위까지 넉넉하게 내려오며 허리에서 양쪽 다리로 연결된다. 번호/브랜드는 UV2에 통합해 천과 함께 움직인다. 원작 자산은 쓰지 않는다.

캐릭터 스튜디오에 컷·급정지 루프와 상체·주름 확대를 추가한다. 해당 씬은 실제 경기와 같은 StreetPlayer/RiggedStreetVisual을 사용하며 사용자 경기와 별도로 열린다. 모바일/육성/가드·포워드·센터의 장기 계획과 현재 시험용 역할 밸런스 범위는 유지한다.
