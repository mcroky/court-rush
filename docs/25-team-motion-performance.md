# v0.10.2 3대3 모션 처리 최적화

## 범위

Godot4.7.2 Standard / Compatibility 유지. 플레이어의 실제 손바닥·발끝 IK와 모션 갱신 주기를 유지하면서 불필요한 복사·할당·반복 변환을 줄인다. 해상도·메시·의상 품질 축소나 선수별 모션 프레임 건너뛰기는 적용하지 않는다. 웹 클라이언트 변경이며 온라인 서버·DB·인증·랭킹 정책은 바꾸지 않는다.

## 구현

- 소스 발 접점 두 곳만 필요한 경로에서45개 전역 뼈 포즈를 복사하던 것을 두 곳으로 줄인다. 전환 시 복구하는 몸통·목·머리·쇄골6개만 레이어 전 포즈를 저장한다. 최종 전신 전환 포즈는45개 모두 유지한다.
- 손 이전 회전·발 목표·발 회전·발목 IK·최종 포즈 배열을 선수별로 미리 확보해 재사용한다. 매 프레임 clear/append와 손 배열 map의 임시 할당을 줄인다.
- 손가락 원본 포즈·자식 오프셋·손 기준 목표·구부림이 같은 경우에만 손가락 말단 회전을 재사용한다. 팔·손목·발·골반은 그대로 매 틱 계산한다. 키가 다르면 기존 손가락 풀이를 수행하며, 캐릭터 체격/접지 초기화 때 키를 무효화한다.
- 같은 풀이 안의 역변환과 프레임 내 고정된 몸통 회전을 재사용한다. 숨겨진 구형 캐릭터의 머리·엄지·손목 장식만 갱신하지 않는다. 손/팔/신발의 호환 좌표와 진단용 다리 풀이, 실제 화면의 머리·손가락·의상 리그는 유지한다.
- 뼈 이름과 부모 인덱스는 리그 생성 때 확정한다. 외부 온라인 포즈를 표시하는 경로는 기존 Skeleton3D 적용을 유지한다.

## 동작 검증

- `tests/motion_cache_test.gd`: 같은 시드·입력으로 연습/1대1/3대3의15,000개 선수 프레임을 비교한다. 달리기·컷·크로스·턴·비하인드·슛·패스·수비 전환, 매 프레임 공 소유·행동·공 위치 및 실제 렌더 뼈와 손바닥 접점의 일치를 확인한다.
- 배포 원본 `118ca46`의 game/actor/team/rig를 별도 리소스로 불러온 독립 비교도 수행했다. 손·발 접점 오차0, 손가락을 포함한 관절 위치 최대0.000000267m, 행동·공 소유·공 궤적 차이 없음. 엄격 검사 한계는 손·발0.000001m, 관절0.00005m다.
- 전체 뼈를 GDScript 작업 버퍼로 옮기는 후보는 동작 일치에도 처리 시간이 증가하여 제외했다. 클립 평가 횟수를 바꾸는 후보도 원본 자세 차이가 발생해 제외했다. 최종 구현은 기존 클립 평가와 접촉 계산을 보존한다.

## 성능 측정

동일 PC에서 Godot headless CPU 처리만 측정했다. GPU나 웹 FPS의 직접 측정치가 아니다. 같은 시드·입력의 원본과 최적화 인스턴스를 한 프로세스에 두고 실행 순서를 프레임마다 바꾸며, 초기90틱을 제외한1,410틱씩 비교한다. 시스템 부하·스케줄링 영향을 완전히 분리하지는 못한다.

| 3대3 CPU 틱 | 원본 | 최적화 |
|---|---:|---:|
| 평균 |3.2815ms|3.0753ms|
| p95 |4.430ms|4.186ms|
| p99 |5.495ms|5.250ms|
| 단일 최대 |13.569ms|9.604ms|

평균 약6.3%, p95 약5.5% 감소. 단일 최대는 OS 부하 영향을 크게 받으므로 지속 개선율로 해석하지 않는다. 1대1 평균은1.1721→1.0908ms였다. 재현 도구는 `tools/benchmark_motion.gd`, 원본 독립 비교 기록은 `artifacts/motion-original-benchmark.log`다. 모든 기기에서 일정 FPS나 모든 끊김 제거를 보장하지 않는다.

## 웹·공개 검증

- Godot 회귀26종 중23종 통과: 모션 동일성, 다리 안정성/발 박자/크로스 핸드오프/시선, 슛 진입/회복/달리는 마무리, 공 보유/슛 연결/의상 형태, 블록 반응/루즈볼 경합/이탈, 접촉/착지, 팀전/육성/온라인 표시/권한 경기, 일시정지. 웹 lifecycle/HUD 반복 쓰기 검사와809개 문구×3번역 검사 통과.
- 기존 절대 자세 기준3종은 실패를 유지한다. `shot_arm_line_test`:336건, `cross_body_flow_test`:226건, `finish_flow_test`:4건. `118ca46`의 독립 actor/rig/game을 실제 불러온 검사에서도 각 실패 수와 최대각·속도·공간 수치가 동일했다. 이 릴리스에서 실패 기준을 완화하거나 해당 자세를 고쳤다고 주장하지 않는다. 기록은 `artifacts/*_test-original.log`, `finish-flow-original.log`와 대응 `v0102-*.log`다.
- `crossover_test`는 숨겨진 구형 메시가 화면 리그인 것처럼 검사하던 경로를 수정했다. 원본에서도 숨김 정강이1건이0.011604m 벗어나던 기존 검사였으며, 현재 보이는 사람형 리그의 팔·다리 길이와 발끝을 검사하도록 바꿨다. 구형 메시를 실제 사용하는 경우에는 기존 검사를 유지한다.12,992표본에서 표시 뼈 오차 최대0.000000582m, 실패0.
- 로컬 웹 전체화면: CSS1920×1080, 실제 캔버스1280×720, WebKit WebGL, 630표본. 프레임 평균16.667ms / p9516.8ms / p9916.9ms /33.5ms 초과0. 모션·의상·해상도 설정은 기존 값이다. 다른 시점의 창 모드 표본에는33ms 간격이 있어 모든 부하에서 일정 FPS라고 주장하지 않는다. 원본 브라우저 비교 시도는 전체화면이 유지되지 않아907×650 창 모드가 되었으므로 직접 개선율 계산에 쓰지 않는다.
- 실제 브라우저에서6명 이동·수비, 크로스오버와 공 보유를 관찰했다. 정량적인 개선율은 위 CPU 비교로 한정한다. 실제 휴대폰 검증은 아직 수행하지 않았다.
