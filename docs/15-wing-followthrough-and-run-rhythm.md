# 45도 슛 양팔 회수와 달리기 발 교대 — 2026-10-26 로컬

## 문제와 적용

사용자는 림에서45도인3점 위치의 릴리즈 직후 양팔 마무리와, 첫 한두 걸음 뒤 발바꿔 뛰기 같은 달리기를 지적했다. 엔진은 Godot4.7.2 Standard/Compatibility를 유지했다. 공통 문서는 앞서 읽은 뒤 수정 시각이 같아 관련 기준을 유지했고 기존 game-feel의 후속 동작 원칙을 적용했다.

- 슛의 가이드 손은0.12초부터 옆으로 벌린 채 머리 높이에 남았고,0.22초에 팔꿈치 목표 산출 방식이 즉시 바뀌었다. 가이드 손은 실제 릴리즈 이후0.22~0.40 위상에서 가슴 높이로 벗어나고 먼저 회수한다. 슛한 손은 기존 손목 꺾기와 높은 팔로스루를 유지한 후 회수한다. 팔꿈치 가이드도0.22~0.40에 연속 보간하고 손목/팔꿈치 회수 축을 동일 림 방향으로 맞췄다. 훅슛 전용 팔 경로는 유지한다.
- 기존 달리기 클립은 speed/7의 별도 시계를 사용했다. 실제 접촉 교대와 어긋나고, 접촉 동작에서 일반 달리기로 돌아갈 때 다시0.40/0.90 위상으로 이동시켰다. 이제 같은 stride의 교대 위상으로 클립을 샘플링하며 추정 발로 다시 이동시키지 않는다. 보이는 발/팔/상체가 같은 발 순서를 따른다.
- 일반 달리기의 정상 보폭 기준을0.72→0.96m, 최소 회수 시간을0.12→0.18초로 조정. 수비 슬라이드·착지 밀기·재출발의 별도 시간은 보존한다. 정지 발의 길이가 닿지 않을 때 몸을 낮춰 지지하게 하고, 출발 첫 지지 발에 남은 자동 발 들기 예약을 제거한다. 같은 발이 연달아 짧게 뜨고 다시 딛는 현상을 실측해 수정했다.
- 회복 자세→달리기 클립 보간 중에는 신발도 실제 보간된 자세에서 받는다. 몸은 보간하고 발만 이미 다음 클립 목표로 보내던 이중 경로를 제거해 슛 회복 뒤 무릎 속도23.31m/s 실패를17.01m/s 이하로 줄였다.
- 새 달리기 자세에서 길게 남은 발을0.09초 만에 슛 자세로 회수하면 무릎 속도19.03m/s가 발생했다. 첫 발 회수0.12초/전체 모으기0.26초로 조정해 같은18m/s 기준을 통과했다. 준비 검사의 첫 지지 시점은0.12초, 모으기 완료는0.27초로 갱신했으며 실제 도약 전 발 접지와 뼈 길이·관절 속도 기준은 유지했다. 슛 입력·득점/탄도·릴리즈·보상·서버는 변경하지 않았다.
