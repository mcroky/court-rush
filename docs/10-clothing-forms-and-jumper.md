# 의상 형태와 점프슛 관절 연결 — 2026-10-26

사용자 요청: 색상만 다른 의상을 넘어 후드티·긴바지·모자·헤어를 추가하고, 가는 끈나시처럼 보이는 저지를 고친다. 이어서 점프슛에서 발 전체가 그대로 떠오르고 내려오는 동작을 개선한다. 기존45본 리그·게임 엔진4.7.2 Standard/Compatibility와 공 소유권·슛 타이밍을 유지한다.

- 저지의 문제 원인은 몸통 원통의 넓은 윗변을 목선처럼 쓰던 구조였다. 작은 목둘레로 모이는 어깨판과 좌우 암홀로 바꿨다. 기존 피부/얼굴과 농구복 등번호의UV2 인쇄는 유지한다.

## 슛 연결 수정

종전 구현은 공중에서 발에 몸과 거의 같은 높이를 더하고, 도약 초반 이후 발목 회전을0으로 돌렸다. 무릎의 상대 위치도 거의 고정돼 발이 수평으로 통째로 상승하는 인상이 났다. 실제 움직이는 발 본에 다음을 연결했다.

1. 슛 준비에서 골반을 내려 하중을 받고,9/100초 밀기 구간에서 무릎을 펴며 뒤꿈치를 든다. 하중 깊이를 늘려30fps에서도 발목만 먼저 펴지고 무릎이 뒤늦게 움직이지 않게 했다.
2. 앞꿈치를 세계 좌표에 유지한 채 발목을 펴고 이륙한다. 양발 지지/착지에는8/18ms의 작은 시차를 둔다.
3. 공중에서 발목 각도를 유지하며 발을 조금 뒤로 접고 무릎을 구부린 뒤 착지에 맞춰 편다. 기존처럼 공중 대부분을 평평한 신발 자세로 보내지 않는다.
4. 앞꿈치 접촉 후65ms 동안 뒤꿈치를 내리고, 골반/무릎 압축 뒤 회복한다. 착지 전 무릎을 미리 꺾어 충격 흡수를 흉내 내는 대신 접촉 뒤 하중을 받는다.

기존 점프 곡선·도약/착지 기준 시간·슛 릴리즈와 경기 판정을 유지했다. 장신/단신 체형의 본 길이를 늘이지 않고 고정 길이 IK로 표현한다.

## 이동 슛의 마지막 디딤 수정 — 2026-10-26 로컬

기존 점프슛 회귀는 골대를 향해 전진하는 한 보행 박자를 주로 확인해, 옆/뒤/대각선 진입에서의 전환 오류를 놓쳤다. 실제 경기 입력으로8방향/6진입 박자를 조사하니, 몸이 골대로 먼저 돌아가고 발은 이전 달리기의 세계 좌표에 남았다. 이전 진단48조건에서 발의 좌우 투영 간격이 최소-0.512m, 준비 후반에도-0.369m로 뒤집혔다. 또한 숨긴 원형 리그의 신발로 회수 목표를 바꾸면서 보이는 발의 박자가 사라졌다.

- actor/game은 이동 슛 진입 방향을 기록한다. 접지/밀기 동안 이 방향을 유지하고, 도약 .098초 이후 .30초까지 골대 방향으로 몸을 돌린다. stationary shot과 레이업은 기존 경로를 유지한다.
- rigged_visual의 독립된 이동 슛 접지는 실제 toe_world와 접지 여부에서 출발한다. 떠 있던 발을 먼저 받고(.09초), 닫는 발을 이어 회수(.24초)한다. 옛 지지발 바깥으로 받도록 폭을 확보하고 넓어진 발 간격은 이륙 뒤 줄인다. 긴 뒤쪽 지지는 도달 한계를 넘으면 앞꿈치로 밀고 떨어진 뒤 실제 렌더 위치에서 닫는 발로 이어진다. 과도하게 골반을 낮춰 붙잡거나 원형 리그의 보폭으로 덮어쓰지 않는다.
- 빠른 슛 릴리즈는 지연하지 않는다. 마지막 gather 시계에서 남은 닫는 발 동작을 shot의 도약 전 구간으로 넘긴다. 접촉 후에만 뒤꿈치를 들어 이륙하며 공 릴리즈/점프 높이/타이밍 보너스 판정은 유지한다. 모은 공으로 다시 드리블하지 않는다.
- 초기 .18초 안에 두 발을 무조건 모으는 시도는 고프레임 무릎 속도34.94m/s와 지지 재해제 문제를 드러냈다. 단순히 골반 하강 상한을 늘리는 시도도 발 미끄러짐과 과도한 하중을 해결하지 못해 채택하지 않았다. 최종은 지지 해제/닫는 발의 연속된 경로로 해결하고 기존 .28m 지지 하강 상한과 검사 기준을 유지했다. 각 실패 출력은 artifacts/shot-entry-before.txt와 shot-entry-matrix*.txt에 보존했다.

## 얼굴 앞 슛 전완 정렬 — 2026-10-26 로컬

사용자 첨부의 왼팔은 손만 공 가까이에 있어도 팔꿈치가 어깨 쪽에 남아 전완이 머리 옆으로 기울어 보였다. 기존 어깨 기준 pole은 서 있는 자세에서도 받치는 전완의 x차이가 약.065m였다. 이동 중에는 원본 달리기의 상체 기울기·비틀림과 고정 월드 높이의 공 목표가 겹쳐 머리와 공의 앞뒤 관계도 달라졌다.

- shot_pose의 공 중심을 실제 head 위치 기준 앞/위로 두고, 준비와 상승 높이를 머리 기준으로 계산한다. 양손의 공 지지 반지름과 손바닥 면은 유지한다. 슛 진입의 entry palm은 머리의 위치 변화와 함께 운반해 회전 중 손이 이전 머리 위치에 남지 않게 한다.
- shot_elbow_guide는 어깨/손목 사이의 실제 두 본 길이로 IK 원을 구하고, 각 손바닥 아래에 팔꿈치가 오도록 원 위의 두 해 중 몸 앞쪽/손목 아래 해를 선택한다. 관절 길이와 손 접촉을 유지하며 전완을 세운다. 공이 떠난 뒤에는 기존 팔로스루/회수 목표로 넘어간다.
- solve의 선택적 굽힘 평면 회전 제한은 슛 팔에만 적용한다. 이전 실제 팔꿈치를 새 IK 원에 투영하고 프레임당10rad/s로 굽힘 방향을 운반한다. 손이나 팔꿈치 좌표를 단순 보간해 본 길이를 늘이지 않는다. 준비 .18초 동안 원본 달리기의 상체 회전을 슛 자세로 정돈하며, 다른 동작의 solve 기본 경로는 바꾸지 않는다.
