# 빠른 제자리 페이크와 방향별 마무리 — 2026-10-26 v0.8.7

사용자는 크게 보이도록 만든0.8.6 페이크가 느리고 굼뜨며, 페이크 뒤에는 현재 방향에 맞춰 레이업이나 골밑 슛으로 이어지길 요청했다. 공개0.8.6 이후 로컬에서 수정·검증한 변경이다. 이후 사용자 요청으로0.8.7에 공개했으며 최종 결과는 아래 공개 완료 절에 기록한다.

## 적용

- 전체 재생 속도만 올리지 않았다. 위협을 빠르게 올리고 정점에서 오래 멈추지 않은 채 회수한다. 긴0.18초 공 진입 보간은 페이크에서0.085초로 줄이고, 회전은0.025초 이후 시작해 접지 도중 각속도를 제한한다. 새 기술 연결 시 실제 신발 방향을 다시 받아 발목이 예전 자세로 돌아가지 않게 한다.
- 단축 초기 펌프에서 양손 속도가14.52m/s까지 튀는 실패를 확인했다. 속도 검사 기준을 늘리는 대신 손 목표를9m/s로 제한했다. 축발·양손 공 접촉·뼈 길이는 유지한다. 잽은30Hz에서도 공 위협이 충분히 보이도록 이동 폭을 조금 보완했다.
- 회수 구간(동작48%)부터 새 페이크/슛/패스 허용. 기술의 짧은 입력은140ms·한 개만 보관, 소비 후 지우며 방향키 유지로 자동 반복하지 않는다. 길게 누르는 슛은 회수 진입까지 의도를 유지하고 짧은 탭은 기존 펌프 규칙을 유지한다. 중단·공 상실 시 대기 입력 삭제.
- 페이크 뒤 골대 방향 입력+슛: 정면3m 이내에서2.4m/s의 짧은 접근을 모으고 기존 한 발 레이업으로 연결. 중립·옆·뒤 입력+슛: 제자리 점프슛. 골대 뒤/3m 밖은 보통 슛. 초기 몸 방향이 반대라 정렬 단계를 거쳐도 선택한 레이업/슛을 잃지 않는다. 새 드리블과 자동 제자리 덩크로 바꾸지 않는다. 기존 W+D/A+D 훅·페이더웨이 조합은 우선한다.
- 1대1·3대3 선택 선수에 공통 적용. 보유 대기 중에는 자동 덩크 거리 안내 대신 일반 슛 안내를 표시하고 슛 준비에서 실제 종류로 전환한다.4개 언어 도움말 갱신. 확대 스튜디오도 동작 길이+0.32초 주기로 반복하며 기본 재생 속도는 정상 속도다.
