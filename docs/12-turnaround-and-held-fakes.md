# 돌아서 쏘기와 드리블 종료 후 페이크

2026-10-26 로컬 수정. Godot4.7.2 Standard/GDScript/Compatibility와 기존 리그 유지. 공개v0.8.3은 이번 작업에서 재배포하지 않았다.

## 요구와 원인

림 반대/옆 방향 입력을 유지하며 슛하면, 이동 슛 코드가 준비 내내 진입 방향을 고정한 뒤 도약 이후에 회전을 몰아서 처리했다. 발 교차는 피했지만 등진 슛의 골반·어깨가 릴리즈 직전에 급격하게 돌아갔다. 돌아서 쏘기는 유지하되 발 접지와 몸 회전이 공 올리기보다 먼저 이어져야 한다.

## 실제 게임 연결

- 림과 몸의 각도 차이가0.65rad보다 큰 일반 슛에 `square` 단계를 추가했다. 현재 보이는 신발에서 축발을 선택하고 착지→축발로 하중 이동→골반/상체 회전→반대 발 받기→기존gather/shot으로 이어진다. 바깥 발은 더 긴 회전 궤도를 따라간 뒤 디딘다. 회전 중 림 방향은 이동한 실제 몸 위치에서 다시 계산한다. 릴리즈 때 갑자기180도 돌리는 경로를 사용하지 않는다.
- 이 단계에서 놓은 슛 입력은 한 번만 예약한다. 짧은 탭은 회전 후 펌프, 충분히 누른 뒤 놓으면 준비 후 슛. 처음 누른 시간도 포함해 회전 종료 직후의 정상 릴리즈를 짧은 펌프로 오인하지 않는다. 점프슛의 릴리즈/탄도/득점 시간은 그대로고 등진 슛에는 지상 회전 시간이 먼저 필요하다.
- `held_ball.gd`가 보이는 축발과 두 손의 공 보유 동작을 함께 관리한다. 드리블 종료 상태를 유지하며 공은 양손 사이에 있고 바운스 시계는 진행하지 않는다. 반대 발만 움직이고 몸은 축발 주위로 이동한다. 코트 경계를 유지한다.

| 공을 든 상태의 입력 | 동작 |
|---|---|
| 방향키/왼쪽 스틱 | 정면은 잽 스텝, 다른 방향은 피벗 페이크 |
| A / 돌파 버튼 | 피벗 페이크 |
| Z / 턴 버튼 | 턴 페이크 |
| C / 투스텝 버튼 | 공 올리기→옆으로 낮춰 빼는 업앤언더 페이크 |
| V / 비하인드 버튼 | 드리블 없이 공을 낮춰 옮기는 다리 사이 공 페이크 |
| X / 헤지 버튼 | 펌프 페이크 |
| D | 기존 슛/짧게 탭하여 펌프, 페이크 후 다시 슛 가능 |

- 방향을 계속 누르면 한 번만 실행하고 반대 방향으로 바꾸면 다시 피벗할 수 있다. 일반 드리블 중에는 기존 기술을 유지한다. 3대3의 현재 조작 선수에도 같은 경로를 적용하며 페이크 후 Q 패스가 가능하다. 모바일 버튼은 보유 상태에 따라 이름을 바꾸고, 팀전 보유 중에는 수비 버튼 자리를 페이크에 사용해 두 줄로 유지한다.
- 화면 이탈·일시정지 때 준비/회전/페이크를 공 보유 대기로 안전하게 바꾸고 예약 슛을 취소한다. 공을 잃으면 회전·페이크 상태도 해제한다. 서버·성장 수치·보상에는 변경이 없다.
- 캐릭터 스튜디오에6개 페이크 확대 미리보기 추가. 한국어/영어/일본어/간체 중국어 조작 이름과 도움말을 수정했다.

## 검증과 실패 기록

- 실제 입력의 무방향/림 방향/반대 방향/옆/대각 이동 후 슛,5기술키, 방향 잽/반전·반복 억제,3대3 선택 선수·페이크 후 패스, 공을 잃었을 때 해제를 검사한다. 보이는 축발의 세계 좌표, 양손 사이 공, 바운스 시계 정지, 릴리즈 방향과 관절 속도를 검사한다.
