# v0.9.0 — 3대3 성장 팀전과 연속 모바일 카메라

2026-10-26. Godot4.7.2 Standard/GDScript/Compatibility, 기존45본 리그와 아이디 인증을 유지한다. `내 선수 → 성장 팀전 시작`은 기존 보상 없는 AI 팀전과 별도 진입이다. 사용자 경기 탭을 초기화하지 않고 독립 QA 탭을 사용한다.

## 선수와 보상

- 계정의 포지션·키·훈련·기술·의상을 경기 시작 스냅샷으로 적용한다. 아군은 나머지 두 포지션, 상대는 가드·포워드·센터로 구성한다. 상대 레벨은 내 레벨1~10, 상대 훈련은 레벨−1로 제한한다. 동료는 기본 능력을 사용한다.
- 11점 또는3분, 동점 다음 득점, Q 패스/E 전환/자동 전환과 기존 림 바운스·블록·리바운드 규칙을 공유한다.
- 조작 선수가 전환되는 기존 흐름에 맞춰 **아군의 직접 조작 기록**을 합산한다. AI 단독 득점은 개인 기여에 넣지 않는다. 실제 슛 방출 시 조작 여부, 패스 후6초 이내 득점, 손 접촉 스틸·블록, 슛 후 첫 공 확보를 각각 기록한다. 득점 사건 중복과 체크볼 초기화로 인한 기록 소실을 막는다.
- 경기 완주 기본40XP/25코인, 승리 추가35XP/20코인. 기여는 득점×2+어시스트×5+리바운드×3+블록×5+스틸×4. 가드는 어시스트·스틸×2 추가, 포워드는 득점×1 추가, 센터는 리바운드·블록×2 추가. 기여는 최대45XP, 기여 코인은 그1/3 내림. 승리 최대120XP/60코인, 패배 최대85XP/40코인.
- 직접 입력 참여12초 미만이면 XP/코인0. 중도 종료는 보상 없음. 보상 결과는 내 선수의 기존 경험치와 지갑에 합산한다. 레벨당 스탯3P·기술1P, 상한20레벨을 공유한다. 팀 전적은 별도 `teamRecord`이며1대1 클리어·승패·컬렉션 해금은 변경하지 않는다.
- 일반 AI 팀전·자유 연습·일반1대1에는 성장 보상 없음. 결과 화면의 재경기는 새 성장 경기 티켓을 받는다. 저장 실패 시 결과와 기여 기록을 세션에 남겨 보상 다시 받기를 제공한다. 결과가 미청구면 새 티켓으로 덮어쓰지 않는다.

## 서버 경계와 저장

기존 탁구왕 Supabase의 `cr_*`와 `court-rush`만 확장한다. `ttk_*`, 공유 Auth·요금제는 변경하지 않는다. `cr_matches`에 `game_mode`(기존 행은duel)와 `setup` JSON을 추가했다. 팀 경기 시작 재시도는 같은 티켓의 선수·상대 스냅샷을 반환한다. 기존1대1 RPC·호출 형식은 유지한다.

서버는 소유자·시간·점수·기여 범위를 검사하고 직접 요청한 XP/코인은 무시한다. 실제 경과20초 이상, 시뮬레이션20초 이상, 남은 시간0~180초, 양 팀 점수0~13점·비동점,11점 조기 종료 또는 시간 종료, 직접 득점≤팀 점수·어시스트≤팀 점수/2 등의 제한을 둔다. 기존 트랜잭션 `cr_finish_match`의 행 잠금과 선수 revision으로 동시 청구·훈련 충돌과 중복 지급을 막는다. 완료된 티켓 재청구는 저장된 영수증을 반환한다.

**기기에서 시뮬레이션하는 PvE**다. 서버는 입력 재생과 모든 접촉의 진실성을 검증하지 않는다. 위 검사를 경쟁전 부정행위 방지 완성으로 소개하지 않는다. 온라인PvP·공개 순위·유료 재화는 이번 범위 밖이다. 서버 설정 스냅샷·기여 기록은 계정 삭제 때 기존 계정 자료와 함께 삭제된다.

## 모바일 줌

기존 카메라는 필요한 거리를1.07배씩 최대14회 검색한 뒤, 멀어질 때 즉시 적용했다. 외곽 이동에서7% 경계를 반복 통과하며 구도가 덜컥 바뀌었다. 이제 고정 시선의 원근 투영에서 좌우·상하 안전 영역에 필요한 거리를 연속 계산한다. 확대·축소 모두 delta 기반 지수 보간(뒤로7/s·복귀3/s)하며2.5% 여유를 둔다. 림·선수·가까운 수비·공중 공의 기존 프레이밍을 유지한다. 캐릭터 이동·물리 속도는 변경하지 않는다.

동일한3초 외곽 이동 회귀 경로: 기존 최대 프레임 변화7%, 수정 후30/60/120fps에서1.067%/0.532%/0.266%. 정지2초 후 줌은 모두1.232553(오차0.000001 미만). 이는 카메라 거리 변화 검사이며 GPU FPS 향상 수치가 아니다. 브라우저 휴대폰 크기 검증과 실제 휴대폰 GPU·발열·Android 검증은 구분한다.
