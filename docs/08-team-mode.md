# 3대3 확장 설계

v0.7.0의 실제 구현은 선수 육성·AI 1대1이다. 현재 game.gd는 수비자·공 소유자·턴 변경을 `1-index`, 두 선수 배열과 두 점수로 처리한다. 여기에 네 캐릭터만 추가하면 패스, 수비 마크, 블록/리바운드 접촉과 공 소유권이 잘못된다. 3대3으로 표시한 미완성 모드는 공개 메뉴에 넣지 않는다.

다음 구현 단위는 AI 팀전이다. 내 선수1명 + AI 동료2명 대 AI3명으로 시작하고, 이후6명의 온라인 동기화는 별도 서버 단계로 구분한다.

- 선수 ID와 팀 ID를 분리한다. 공 소유자는0~5 중 한 명 또는 공중/루즈볼이며, 공격권은 소유자와 별도로 팀에 귀속된다. 턴·외곽 클리어·득점·경기 종료는 팀 기준이다.
- Q 패스, E 수비 선수 전환, 기존 이동/슛/드리블 입력을 공유한다. 모바일에는 문맥 패스·수비 전환 버튼을 추가하되 터치 화면을 기존 기술 버튼으로 더 채우지 않는다.
- 패스 준비→보내는 실제 손에서 방출→가로채기 가능한 공 비행→받는 손 접촉→소유권 전환을 독립 동작으로 만든다. 공을 순간이동하거나 판정과 다른 손에 붙이지 않는다.
- 동료 AI는 가드의 외곽 배급, 포워드의 컷과 마무리, 센터의 스크린·골밑·박스아웃을 나눈다. 수비는 마크 대상, 헬프와 복귀, 슛 이후 박스아웃 상대를 선택한다. 여러 AI가 같은 자리에 겹치거나 모두 공만 쫓는 행동을 막는다.
- 리바운드·블록·스틸은 팀/손 접촉 후보 전체에서 공중 사건 하나를 원자적으로 확정한다. 두 명이 동시에 캐치하거나 블록 뒤 공이 원래 슈터에 붙는 오류를 검사한다.
- 첫 단계는 보상 없는 AI 팀전으로 접촉/패스/성능을 검증한다. 육성 보상은 팀 경기 서버 티켓·시간·플레이어 기여/결과 검증을 구현한 뒤 연동한다. 온라인 경쟁전은 서버 권위의 소유권·입력 검증·재접속을 추가한 뒤 제공한다.
- 같은45본 리그와 위치별 키/운동능력, 기존1대1 모션을 유지한다. 6명 실시간 스킨 메시·그림자·공 판정의 모바일 성능과30/60fps 동시 경합을 별도로 검증한다.

출시 완료로 표시할 조건: 패스/받기/가로채기, 수비 전환, 팀 클리어, 전원 리바운드·블록 경합, 두 팀 득점과 종료, 작은 화면 조작·기기 성능 검증. 설계만으로 3대3 구현 완료를 주장하지 않는다.
