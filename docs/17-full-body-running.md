# v0.8.10 · 전신 달리기와 반대 팔 스윙

사용자가 첨부한 마네킹 달리기를 기준으로 더 크게 전진하는 무릎·앞발, 긴 회수, 큰 반대 팔과 몸통의 연결을 요청했다. 엔진은 실행 파일과 project.godot에서 확인한 Godot4.7.2 Standard/GDScript/Compatibility를 유지한다. 공통 기준·router/설치 목록·game-feel은 이전 작업에서 읽은 파일과 수정 시각이 같아 해당 기준을 적용했다. 서버·인증·저장·이동 능력 수치는 바꾸지 않는다.

## 원인과 변경

- 이전 공중 발은 월드에서8m/s로 목표를 추적했다. 몸이4~5m/s로 전진하면 발 자체의 전방 회수에는 나머지만 남아, 소스는 앞발을 뻗는데 실제 발은 몸 뒤에 남았다. 비접촉 달리기 발은 몸의 이동량을 먼저 따라간 뒤 로컬 스윙8m/s 제한을 적용한다. 지지 발은 월드 앵커에 남긴다.
- 이전 발 지지 한계 보정은0.16초의 별도 작은 스텝을 만들어 원래 회수 전에 다시 딛었다. 정상 달리기는 이륙 후 같은 소스 스윙으로 돌아간다. 다른 접촉 동작의 안전 스텝은 유지한다.
- 원본 팔 궤적 뒤에 빈손 팔의 작은 전후 목표, 드리블 반대 팔의 견제 목표(.26±.09m)를 덮어썼다. 정상 달리기의 빈손 양팔·드리블 반대 팔은 소스의 손/팔꿈치 경로를 사용한다. 공을 다루는 손·정지 견제·수비·스킬 손 전환은 각 접촉 동작을 유지한다. 자유 팔의 뒤쪽 가동 범위를 늘리되 관절 길이는 유지하고 손가락을 편하게 접는다.
- 정상 달리기 거리 기준1.30→1.70m, 회수 최소0.22→0.27초/상한0.26→0.36초. 몸의 이동 속도는 그대로다. 소스 지지 창은 주기의0.25→0.33으로 늘려 밀기 뒤 회수로 연결한다. 첫 스윙은 idle 보간 중 가짜 착지 없이 회수 호를 유지한다.
- 달리는 신발이 실제 앵커에서6mm 이상 벗어나면 접지 표식을 해제한다. 이전55mm 표식은 이미 이륙한 신발도 고정 상태로 남겨 실제 접촉 검사에서20mm 이동으로 기록됐다. 수정 후 실제 연속 지지 이동2.57mm 이하, 기존8mm 검사 통과.

## 실패 보존과 선택

- 최초 실루엣 진단24조건은 작은 팔 궤적·전방 무릎 부족을 드러냈다. 초기 앞무릎 각도 최저1.007rad, 자유 팔 전후 궤적 최저0.186m였다. artifacts/v0810-silhouette-before.txt.
- 새 보폭에서 별도 안전 스텝을 남기면 동일 발 재착지44~54회가 나타났다. 해당 스텝을 제거한 최종36조건은 반복0. 전역 발 목표 속도를 늘리는 대신 몸 이동과 로컬 회수를 분리했다.
- 진단 중 지상 후방 발 거리0.55m를 모든 신장에 요구했으나, 큰 체형은 원본 포즈·접지 구간과 일치하지 않았다. 지상 거리와 발끝 이륙 시 다리 펴짐은 계속 출력하되 공통 성공 기준으로 채택하지 않았다. 새 실루엣 검사의 통과 기준은 전방 무릎 각도1.25rad와 자유 팔 궤적0.62m(빈손)/0.48m(드리블)이며, 종전 발 접지·관절 안정성 검사 기준은 유지했다. 따라서 모든 체형의 후방 다리가 첨부 스틸과 완전히 같다고 주장하지 않는다.
- 골반을 일정하게/주기적으로 더 높이는 실험과 발목의 강제 큰 회전은 원하는 체형 공통 후방 선을 만들지 못했고 접촉·무릎 검사에 실패해 제외했다. source 발목 회전과 기존 높이를 유지한다.
- 로컬 발 회수10m/s는 슛 회복120Hz 한 조건에서 무릎19.66m/s로 실패했다. 최종8m/s에서17.48m/s 이하로 기존18m/s 기준 통과. 관절 제한을 늘려 통과시키지 않았다.
