# 스틸왕의 이동·드리블 상대

2026-10-28. 사용자 제보: 상대가 가만히 있으며 돌아다니고 단계가 높을수록 드리블 기술을 써야 한다.

기존 상대는 tier1에서 x 폭0.54m/z 폭0m,8.5초 이동0.81m에 그치는 작은 sin 왕복이었다. tier6도 좌우 왕복뿐이며 기술 사용은 없었다. 기존 검사는50프레임에서2cm만 이동하면 통과해 사용자 체감과 달랐다.

Godot4.7.2/GDScript/Compatibility·기존45관절과 접촉 로직을 유지한다. game-ai 스킬의 의도/조향 분리 기준을 사용하며 개방된 반코트의6개 이동 목표를 순환한다. navmesh·모션 생성기·새 모델을 도입하지 않는다. 기존 플레이어용 duel_control을 의도 실행기로 재사용해 동일한 크로스오버·비하인드·헤지테이션·턴·투스텝의 루트/공/손 동작을 사용한다. 일반 AI와 온라인 입력 경로는 바꾸지 않는다.
