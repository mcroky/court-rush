# 코트러시 v0.7 계정·선수 육성·웹 공개 설계

2026-10-24. 사용자 요청으로 모션 추가 보정은 뒤로 두고 육성형 공개판을 우선한다. Godot 4.7.2/Compatibility와 기존 모션 리그를 유지한다.

## 범위와 출시 경로

GitHub Pages는 정적 게임과 UI를 제공하고 Supabase는 아이디 인증 어댑터와 선수 저장을 제공한다. 사용자 선택: 연결된 조직에 court-rush 전용 프로젝트를 무료일 때만 생성. 기존 다른 게임의 DB/인증 설정은 변경하지 않는다. 공개 URL 목표는 https://mcroky.github.io/court-rush/ 이며 실제 배포 확인 전 공개 완료로 표시하지 않는다. Roky Studio 카드/업데이트/의견 선택지도 실제 주소로 함께 연결한다.

우선순위는 ID 가입·로그인 → 선수 생성 → AI 1대1 단계 도전 → 경기 보상 → 스탯/기술 훈련 → 다음 상대다. 자유 연습과 기존 일반 1대1은 보상 없는 모드로 유지한다. 3대3은 가능한 경우 별도 AI 팀전으로 추가하며 사람6명의 온라인 매칭/네트워크 동기화와 구분한다.

## 아이디 인증 결정

아이디는 영문 소문자/숫자/밑줄 4~20자로 정규화하고 비밀번호는12~72자로 받는다. 실제 이메일 주소를 입력·인증하지 않는다. 서버가 무작위 내부 Auth 식별자를 만들고 사용자 아이디↔Auth 사용자↔내부 식별자를 서버 전용 테이블로 연결한다. 내부 식별자는 실사용자 이메일이나 아이디의 예측 가능한 변환이 아니다. 가입은 Supabase Auth admin createUser와 email_confirm을 서버에서 사용하고, 로그인은 비공개 매핑을 조회한 서버에서 Auth signInWithPassword로 검증한다. 비밀번호를 앱 테이블·브라우저에 저장하거나 자체 해시 검증하지 않는다. 실제 이메일을 수집하지 않고 메일도 발송하지 않는다.

별도 가입 가능 아이디 조회 API는 제공하지 않는다. 로그인 오류는 계정 존재 여부를 구분하지 않는다. IP/아이디 단위 요청 제한, 사용자 JWT의 서버 검증, 세션 유효성 확인, 소유권 검증과 서비스 역할 전용 쓰기를 둔다. 공개 빌드에는 서버 비밀 키를 포함하지 않는다.

가입 때128bit 이상의 무작위 복구 코드를 한 번 보여주고 서버에는 해시만 저장한다. 아이디와 복구 코드로 비밀번호를 재설정하며, 코드 없이는 이메일 복구를 약속하지 않는다. 재설정 뒤 복구 코드를 회전하고 세션을 폐기한다. 로그아웃과 계정 삭제를 구분하고 계정 삭제는 재인증 후 선수/경기 자료와 Auth 사용자를 함께 삭제한다. 브라우저에는 명시적으로 선택한 로그인 유지용 세션만 보관하고 비밀번호/복구 코드는 보관하지 않는다.

## 선수와 육성

가드178cm/76kg, 포워드190cm/87kg, 센터204cm/103kg. 가드는 이동·핸들링·스틸, 포워드는 돌파·마무리·중거리, 센터는 골밑·블록·리바운드·몸싸움에 강하다. 키와 운동능력은 실제 화면 리그와 경기 능력치에 적용한다. 손·공의 실제 접촉, 지지 발, 도약/릴리즈 이벤트를 스탯으로 우회하지 않는다.

원본은 버전/포지션/경험치/투자 스탯/스킬 단계/사용 가능 포인트/최고 클리어 단계다. 합산 능력치는 원본에서 계산한다. 레벨당3 스탯 포인트와1 기술 포인트, 각 능력치 투자 상한20·합산99로 제한한다. 기본 행동은 모두 쓸 수 있고 기술 훈련은 회복/성공 효율에 작은 보너스를 준다. 성장 때문에 기존 동작 타이밍이나 팔다리 길이를 매 프레임 바꾸지 않는다.

## 보상 권한과 한계

서버가 현재 도전할 수 있는 단계와 선수 스냅샷을 확정하고 경기 ID를 발급한다. 보상량/레벨/포인트는 클라이언트가 보내지 않으며 서버가 테이블의 경기 ID·소유자·경과시간·스코어 범위와 단계 조건을 검사해 정해진 보상만 지급한다. 한 경기 한 번 지급하고 트랜잭션 잠금으로 중복 보상·동시 훈련의 포인트 이중 소비를 막는다. 응답 유실 때 같은 경기 ID로 재요청하면 저장된 결과를 돌려준다.

현재 AI 경기 시뮬레이션은 클라이언트에서 실행하므로 완전한 부정행위 방지나 서버 권위의 경쟁전을 주장하지 않는다. 첫 공개판은 솔로 PvE 육성이며 공개 순위/현금성 경제/유료 능력치/온라인 경쟁 보상은 제공하지 않는다. 경쟁전 도입 전에는 서버 시뮬레이션 또는 입력 재검증을 별도로 구현한다.

## 모바일과 개인정보

웹과 향후 Android는 같은 계정/선수 저장을 사용한다. 세션 만료/오프라인/저장 실패를 화면에 알리고 서버 성공 전 포인트 지급으로 표시하지 않는다. 계정 삭제 외부 웹 진입점과 개인정보 안내를 둔다. 웹의 카카오뱅크 링크는 공통 안내를 사용하며 Google Play 채널에는 자동 포함하지 않는다. 실제 AAB·서명·기기 검증은 별도이며 이번 웹 공개와 동일시하지 않는다.

## 실제 서버 선택

전용 프로젝트는 비용 조회에서$0이었으나 활성 무료2개 제한으로 생성되지 않았다. 사용자 추가 승인에 따라 내일은 탁구왕 프로젝트 `jcmceanrkrrigaafoitm`에 `cr_*` 테이블/함수와 `court-rush` Edge Function을 추가했다. `ttk_*` 자료·함수와 Auth 제공자/이메일 설정은 변경하지 않았다. 서버는 기존 무료 프로젝트를 공유하며 유료 생성/업그레이드를 하지 않았다.
