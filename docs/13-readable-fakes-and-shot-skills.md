# 읽히는 페이크·슛 조합·첫 바운드 확보 — 2026-10-26

사용자는 상대가 경기 화면에서 볼 수 없을 정도의 정적인 페이크로는 속이는 재미가 없다고 지적했다. 기존 축발·두 손 보유 보정은 유지하고 실루엣과 위협을 보여주는 시간을 키웠다. 과장과 관절의 순간 이동은 구분한다.

## 입력과 모션

| 기존 입력 조합 | 동작 |
|---|---|
| W+D 또는 A(돌파)+D, 림 3.5m 이내 | 점프 훅슛 |
| 위 조합 + 림 반대 방향, 또는 3.5m 밖 | 페이더웨이 |
| 이동 중 기존 D, 림과 몸 방향이 크게 다름 | 지상 디딤에서 공중까지 이어지는 턴 슛 |
| 드리블 종료 후 기존 A/Z/C/V/X·방향 | 피벗/턴/업앤언더/다리 사이/펌프·잽 |

- 슛은0.18초 이상 누르고 모은다. 짧은 탭은 기존 펌프. 모바일은 기존 돌파+슛 버튼을 함께 누르며0.12초 이내의 드리블/피벗 진입에서 슛 조합으로 전환할 수 있다. 수비 W·D와 기본 D 레이업/덩크는 유지한다. 조합은 AI1대1·3대3 공통 입력 경로를 쓴다.
- 훅슛은 반측면으로 공 보호, 팔꿈치 선행과 가이드 손 분리, 머리 위 한 손 릴리즈·손목 회수다. 페이더웨이는 지상 디딤 뒤 최대0.68m 뒤 이동과 공중 기울임, 착지 압축으로 연결한다. 코트 경계에서 이동을 제한하며 성공을 보장하지 않는다. 기존 슈팅/마무리 육성 수치 적용, 신규 유료/계정/서버 변경 없음.
- 이동 턴은 약66%를 지상에서 준비하고 남은 회전을 공중에서 끝낸다. 일반 슛0.22초 대비 회전/신규 조합의 실제 릴리즈는0.34초. 팔만 별도 위상으로 맞추고 발·무릎의 도약/착지 시간은 기존 것을 유지한다. 회전 중에는 공이 실제 손에서 나오며 마지막 프레임의180도 회전으로 처리하지 않는다.
- 공 보유 모션은0.62~0.95초, 위협을 보여주는 정점 구간을 둔다. 공의 상하/좌우 경로와 어깨·몸통의 반대 회수를 기술별로 구분한다. 축발과 뼈 길이는 고정한다. 피벗·잽·다리 사이0.12초, 턴0.12/0.36초, 업앤언더0.12/0.54초의 접지에 마찰음. 기존9개 음향 풀과 CourtSFX 버스/음량·음소거 사용. 새 음원·라이선스 추가 없음.
- 루즈볼은 공 이동 선분과 몸 캡슐/손 구의 실제 접촉으로 확보한다. 첫 바운드 대기시간이나 낮은 높이/idle 조건은 제거. 상대 소유 공·정상 슛 비행에는 관여하지 않는다. 내려치는 블록 손만으로 공을 자동 재포획하지 않으며 몸 접촉은 가능하다. 박스아웃은 실제 진입·위치 경합으로 작동하고 이미 몸에 닿은 공을 추상 차단 플래그로 무시하지 않는다.
