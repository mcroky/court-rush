2026-10-28 요청: 코트8→24단계, 자유투/리바운드/3점슛/스틸/2대1, 육성 보상. 추가 답변으로2대1은 내 선수1명 대 AI2명. 모바일에서는 복잡한 목록·조작을 추가하지 않는다.

리바운드는 실제 양손·공 접촉과 공중 캐치를 충족해야 성공한다. 바닥 습득과 상대 확보는 실패 회차다. 상대와 박스아웃·경합하며, 단계별 상대 능력치와 출발 유예를 높인다. 스틸은 손을 뻗어 실제 접촉한 기존 판정을 사용하고 상대 좌우 움직임·능력치를 높인다. 성공을 버튼 누름으로 판정하지 않는다. 슛은 기존 확률·릴리즈 보너스와 실제 궤적을 사용한다.

코트1~8의 이름·보상·기존 체감은 유지한다.9~24는 레벨11~20, 추가 기본 능력치(상한96), 압박 계수1.025~1.4와 판단 간격의 연속 상승으로 난도를 조정한다. 포지션별 강점은 유지하므로 서로 다른 역할의 모든 개별 능력치가 단조 증가하는 것은 아니다. 플레이 체감과 각 포지션의24코트 전체 완주 밸런스는 추가 관찰 대상이다.

1대2는 기존 팀 경기의 ID체계와 실제 패스/블록/리바운드/체크볼을 사용하되 참가자는0,3,4만 사용한다. 숨겨진 선수는 패스 대상·공 획득·충돌·수비·모션 갱신·라벨에서 제외한다. 일반3대3 진입 시6명으로 복원한다.

## 모바일·번역

도전 센터는 종목 선택 하나, 목표 카드 하나, 단계 선택 하나와 시작 버튼으로 구성한다.30단계를 동시에 펼치지 않는다. 코트 목록은8개씩3구간으로 나누고 다음 코트가 있는 구간을 기본 선택한다. 경기에는 새 HUD/키를 추가하지 않는다. 기존 점수판에 성공/목표·회차·남은 시간, 기존 터치 버튼 중 해당 종목에서 쓰는 것만 표시한다.

로그인 전에는 보상 없는 체험이 가능하다. 로그인한 선수는 서버 티켓으로 시작하며 종목별 진행을 저장한다. 한국어·영어·일본어·중국어 자료를 추가했다. 웹390×844와 더 작은 화면의 실제 표시·스크롤을 확인한다. Android 입력은 기존 행동 추상화를 유지하며 실제 휴대폰/AAB/Play 검증을 대신한다고 주장하지 않는다.

## 저장·보상·서버

Neon을 우선 후보로 검토하되 이번에는 사용자가 확정한 기존 Supabase `jcmceanrkrrigaafoitm`의cr_* 영역을 유지한다. 신규 DB/인증 이관은 기존 선수·세션·의상·온라인 Elo의 별도 이관 검증이 필요해 이 콘텐츠 추가와 묶지 않는다. 공유Auth·ttk_*·온라인 서버는 변경하지 않는다.

기존 player.version1을 유지하고 누락된 challengeRecord는 빈 기록으로 정규화한다. 원래 cleared는1대1 코트에만 사용하며 도전 기록은 kind별 cleared/best/games로 분리한다. 첫 성공 XP는100+단계×30, 코인은70+단계×15. 재도전 성공30%, 실패20XP/10코인. 기존 레벨20·포인트 상한 유지.

서버는 mode/kind/tier와 이전 해금을 검사해 setup을 저장하고 requestId로 시작 재시도를 묶는다. 완료 시 setup으로 목표·제한시간을 다시 계산하며 사용자 소유권/기회·정수·시간 범위/경과시간을 검사한다. 기존 cr_finish_match 트랜잭션으로 보상1회 지급과 동시 수정 충돌을 처리한다. PvE 시뮬레이션·종목 기록은 클라이언트가 계산하므로 완전한 부정행위 방지를 주장하지 않는다.

원격 스키마 조회 후 cr_matches의 stage 상한8→24와 game_mode의challenge 허용만 변경했다. 기존 행·RLS·GRANT는 건드리지 않는다. Supabase CLI가 설치되지 않아 원격 apply_migration이 발급한 실제 버전20261028102806으로 로컬 이력을 보관했다. 새 테이블은 없다. Edge Function은기존 자체 인증/verify_jwt=false 설정과 online.ts·의상 자료를 유지해 배포했다.
