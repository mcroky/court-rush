# 온라인 대전방·내 선수·Elo 랭킹

2026-10-27, v0.10.0. 사용자 확정으로 v0.9.8의 균등 능력치 방식을 변경했다. 기존 장착 외형뿐 아니라 저장된 포지션·키·체중·훈련 스탯·스킬을 적용한다. Godot 4.7.2 Standard / Compatibility와 기존 Render Free + Supabase 구성을 유지한다.

## 경기와 방

공개방 개설·목록 입장 또는 자동 매칭은 정식 온라인 대전이다. 비공개 연습은 8자리 무작위 코드를 받은 상대만 참가하며 공개 목록에 표시되지 않는다. 두 사람 모두 준비하면 한 쌍으로 코트에 배정한다. 코트가 사용 중이면 두 사람을 분리하지 않고 먼저 준비된 순서로 기다린다. 준비 취소·이탈·10분 만료로 대기를 해제한다. 경기 로딩 취소 시 비공개 참가자를 정식 자동 매칭으로 보내지 않는다.

90초·11점, 동점 연장 최대 60초. 명시적 이탈과 재접속 20초 초과는 기권, 서버 장애·전체 이탈은 무효다. 서버는 한 경기씩 판정하며 온라인 3대3과 Android/Play 공개는 이번 범위가 아니다. Free의 선점 지연과 cold start 한계는 [기존 운영 기록](23-online-duel-implementation.md)을 따른다.

## 저장·검증 경계

- 브라우저는 일회용 참가권과 조작만 보낸다. Edge는 실제 저장 선수에서 외형·attributes를 산출하고 경기 등록 시 최신 기록을 다시 읽는다. 클라이언트의 능력치·점수 주입을 무시한다. 경기 시작 이후 설정을 고정하고 재접속에도 같은 외형·능력치를 사용한다.
- 두 슬롯 모두 자신의 메시·후드·헤어 등 장착 형태를 적용한다. 실제 판정 리그와 화면의 모델 루트·45본 변환을 복제한다. 화면에서 나가면 기존 AI 메시와 선수 외형을 복원한다.
- 마이그레이션 `20261027025503 court_rush_online_career_ranking`, 재현 SQL `supabase/online-ranking.sql`, Edge `court-rush` v9. v1 등록도 유지해 서버 순차 배포를 지원한다.
- `cr_online_ratings`와 RPC는 브라우저 직접 접근을 차단한다. Edge만 service_role로 호출하고 Render에는 기존 코트러시 전용 키만 둔다. 다른 앱 키·`ttk_*`·공유 Auth는 변경하지 않는다.
- 사용자에게는 선수 이름·전적·점수만 공개하고 계정 ID·세션은 공개하지 않는다. 공개방 제목·방장 이름은 공개 목록에 표시한다. 코드와 비공개방은 참가자에게만 보인다. 개인정보 안내와 4개 언어에 반영했다.

## Elo

AI 육성 기록과 별도 저장한다. 초깃값 1,000, K=32, 기대 승률 `1/(1+10^((상대-나)/400))`, 결과 승 1·무 0.5·패 0. 같은 점수끼리 승패는 +16/-16, 더 높은 상대에게 이기면 더 오른다. 비공개 연습·취소·서버 무효는 전적·Elo에 반영하지 않는다. 추가 XP·코인은 없다.

경기와 양쪽 점수 행을 정렬해 잠그고 결과·승패·점수를 한 트랜잭션으로 반영한다. 같은 경기의 재시도·반대 승자 재전송은 최초 확정 결과를 돌려준다. 결과 저장이 늦으면 대기 표시 후 실제 확정 값만 전달한다. 상위 50명과 내 순위를 표시하며 동점자는 같은 순위다.

## 검증

- 실제 Supabase + WSS + Godot 20개: 저장 선수/조작 위조 거부, 방 대기 중 장착 변경 반영, 동일 점수 -16/+16, 높은 상대 승리 +17, 비공개 미반영, 네 번 동시 정산 1회 처리, 잘못된 득점·승자 거부, 공개 랭킹과 직접 쓰기 차단, XP/코인 불변.
- 게이트웨이 8개: 중복 탭·입력 주입·예약 경쟁·두 실제 슬롯·재접속, 공개/비공개 목록과 코드·양쪽 준비·쌍 유지 대기·지연 저장.
- 실제 화면 리그: 가드178cm·센터204cm와 서로 다른 훈련값, 상대 후드 형태·카메라·자세/판정 손바닥 대조 최대 0.223mm, 퇴장 시 AI 메시 복구.
- 기존 rules/game/team_match/team_career_gameplay/online_duel/view, 육성·의상·웹 lifecycle 통과. 803개 원문 × 3개 번역 검사 통과. Web export 46.3MiB, gzip 17.7MiB.
- Security advisor: 신규 서버 전용 RLS/no policy INFO는 의도된 차단이며 실제 직접 접근 거절 확인. 기존 `ttk_save_progress` 및 공유 Auth leaked-password WARN은 변경하지 않았다. [검사 기준](https://supabase.com/docs/guides/database/database-linter?lint=0008_rls_enabled_no_policy).
