# v0.9.7 루즈볼 추격·수습과 아웃 이후 연결

## 바뀐 흐름

- 기존 아웃 처리는 공 소유·선수 위치를 즉시 체크볼 시작 상태로 재배치했다. 공이 밖으로 나간 직후 상대가 이미 공을 든 화면으로 바뀌는 원인이다. 아웃/루즈볼 정체에 `check` 단계를 두고 휘슬, 선수의 복귀, 공 전달, 수습 후 재개로 연결한다. 경기 시계는 이 동안 멈춘다. 순간 재배치 없이 기존 카메라 추적을 유지한다.
- 공을 밖으로 쳐낸 마지막 터치에 따른 공격권은 유지한다. 블록 아웃은 슈터 팀 체크볼, 일반 슛 아웃은 반대 팀이다. 1대1·3대3에 같은 정지/재개 제어기를 쓴다. 다른 게임 모드 시작은 기존 명시적 초기화를 따른다.
- 루즈볼 추격은 실제 공과 같은 중력·바운스 감쇠를 짧게 예측해 도달할 지점을 선택한다. 공을 쫓을 때 림을 바라보던 AI를 이동 방향으로 돌리고 마지막 접근을 감속한다. 낮은 공에 가까워지면 상체를 낮추고 손을 준비한다.
- 공 수습은 진입점과 짧은 관성을 월드 좌표로 보존한다. 도중에 몸을 돌려도 공의 시작점이 몸 주위를 회전하지 않는다. 달리기 발 교대를 유지한 채 양손으로 가슴에 모으고 다음 드리블까지 연결한다. 기존 공중 리바운드 캐치, 실제 몸/손 접촉 획득과 블록 직후0.18초 이탈 구간은 유지한다.
- 복귀 중 정면으로 서로 자리를 바꾸는 선수는 옆으로 비켜 지나간다. 도착점의 몸 겹침을 순간 이동으로 해결하지 않는다.
- 블록 타격 직후8m/s의 옆 속도와7m/s의 아래 타격은 유지한다. 바닥 충돌 뒤 수평 감쇠만 블록 공은0.42, 일반 림 공은 기존0.76으로 구분해 추격할 기회를 남긴다. 블록 연습의 슈터 대기 상태는 타격 뒤 풀고, 루즈볼 자동 회수 제한은6초로 늘린다.
