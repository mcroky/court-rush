# 온라인 조작의 로컬 예측

2026-10-28. 두 기기의 온라인 끊김 제보와 싱글 플레이 수준의 조작 반응 요구에 대한 v0.10.4 작업.

기존 표시는 상대뿐 아니라 내45개 관절도100ms 보간 지연을 거쳤다. 미확인 입력의 단순 이동 오프셋만 적용했고, 동작·수비·근접 상황에서는 예측하지 않았다. 서버 부하를 줄인 v0.10.3만으로 내 입력의 왕복 대기를 없앨 수 없었다.

## 구현

내 입력을60Hz 물리 루프에서 바로 읽고 카메라 방향을 월드 방향으로 변환한다. 기존 싱글 플레이의 `duel_control`·Actor 이동/동작·실제45개 관절 IK를 시각 예측용 숨겨진 sandbox에서 실행한다. 상대는 기존 서버 포즈 보간을 사용한다. 이 sandbox는 전체 match.step·공 비행 결과·득점·보상 RNG를 실행하지 않으며 저장이나 결과 보고도 하지 않는다.

내 미확인 입력의 실제 이동량을 최대24프레임 기록하고 서버 ack에 따라 제거한다. 서버 위치+미확인 이동량과의 오차를 지수 보정하고 한 프레임 보정 속도를2.1m/s로 제한한다. 예측 진입/종료는80ms에 걸쳐 포즈를 섞는다. 서버가 소유권을 바꾸거나 체크볼·데드볼·종료를 전달하면 예측을 취소한다.300ms 이상 새 상태가 없으면 추측을 중단한다.1.5m 이상 오차·서버가 거절한 동작도 서버 표시로 복귀한다.

슛 준비·드리블·수비 동작과 내 슛 미터는 로컬에서 시작한다. 공 소유권·접촉 성공·공중 비행·득점·승패/Elo는 서버 결과만 표시한다. 기존 장착 외형·체격·육성값을 그대로 사용한다. 서버에 선택적 드리블 위상·보행 위상·드리블 손 정보를 추가하되 protocol1/rules duel-career-v2를 유지한다. 이전 클라이언트는 추가 필드를 무시한다.
